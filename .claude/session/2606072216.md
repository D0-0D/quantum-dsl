## Resolution (M1 complete)
The "overlapping facets" failure was bisected to two distinct root causes (both fixed):
1. **`_gmsh_mesh.define_size_fields` clamp bug** — it set `Mesh.MeshSizeMin = min_size`, which
   clamped the JJ refinement field's `SizeMin` (`max_size_jj = 0.5 µm`) back up to `min_size = 2 µm`.
   Fix: `effective_min = min(min_size, max_size_jj)` when a JJ field exists. (Legacy path unaffected —
   its default has `min_size == max_size_jj`.)
2. **JJ as a meshed conductor** — a 2 µm-wide 2D surface embedded at z=thickness/2 inside a 2 µm slab
   can't be tet-meshed under forced refinement, and physically a JJ in an electrostatic C-extraction is
   a **lumped element** (meshing it shorts the two pads). Fix: `populate_tracker_from_geo` removes JJ
   surfaces from the mesh (`occ.remove`), while the GDS branch still emits them (layer 20). Future
   Eigenmode/Driven milestones handle the JJ as a lumped port boundary.
3. **Palace mesh path** — `geo_build` set `Model.Mesh` relative to cwd, but `run_palace` cd's into the
   config dir. Fix: `Model.Mesh = <mesh basename>` (config + mesh share `out_dir`).
