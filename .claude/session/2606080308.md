## Locked decisions (post-workflow synthesis)
- **Physics core = lumped-oscillator INVERSE-capacitance method** (NOT the naive Maxwell
  diagonal). Invert the qubit-node submatrix once; `E_C,i = (e²/2)[C⁻¹]_ii`,
  `C_Σ,i = 1/[C⁻¹]_ii`, `g_ij` from `[C⁻¹]_ij`. Reasoning: using the Maxwell diagonal
  `C_ii` as C_Σ double-counts the coupling cap when the other terminal is itself a qubit
  node (two_pads case → ~hundreds of MHz f01 bias). The inverse method is rigorous,
  **reduces EXACTLY to `e²/2C_ii` for a single isolated island** (Case-1 values unchanged)
  and to `½(C_g/√(C_i C_j))√(f_i f_j)` for N=2, but stays correct for N≥3 (naive form
  drifts up to ~32%). Needs only a tiny pure-Python Gauss-Jordan inverse — no numpy.
- **Closed-form transmon** (leading order): `E_J=(ħ/2e)²/L_J`, `f01=(√(8 E_C E_J)−E_C)/h`,
  `α=−E_C`. Constants `e`,`h` hardcoded exact-SI-2019; `ħ=h/2π` derived. Each qubit
  carries `EJ_over_EC` + a `validity` note (two_pads EJ/EC≈21 is marginal).
- **No new heavy deps**: scqubits absent in metal-env; implemented standalone. Optional
  GATED cross-check against qiskit-metal `Hcpb` exact CPB diagonalisation (importorskip).
- **Sidecar input block = NEW top-level `circuit_model:` key** (NOT `circuit`/`hamiltonian`
  — those are legacy full-DSL ROOT_KEYS with a different shape; the geo sidecar never feeds
  the legacy builder so no collision). Shape: `circuit_model.qubits: [{name, island|islands,
  L_J|E_J}]`. Output section in chip.results.yaml = `hamiltonian:` (distinct artifact).
- **Unit parsing**: NEW `_parse_unit_value` with explicit SI-prefix→multiplier maps
  (`10nH`→1e-8 H; `16GHz`→E_J/h×h Joule). **Explicit unit REQUIRED** (bare number rejected:
  10 H vs 10 nH is a 1e9 footgun). The existing length parser (µm) / `_parse_scalar_with_
  optional_unit` (drops the prefix) must NOT be reused.
- **tier** is DESCENDING: 3 = C-matrix (M3), 2 = +Hamiltonian (M6). `write_results_sidecar`
  derives `tier = 2 if circuit_model else 3` (not caller-passed) + emits a self-describing
  `tier_meaning` note.
- **islands: tuple** (schema future-proof for floating/differential qubits); solver gated to
  len==1 for M6 (raises "multi-island … not supported yet" otherwise).
- **DEFERRED**: geo_names enrichment of the structured `terminal` label in the artifact
  (not needed — islands bind by group name, already the SSOT). Coupling whitelist (`couplings:`).
