## 物理根因与修复 (本轮核心)
qm4q (carved-ground 设计) 电容系统性偏低 ~30%, 根因 = **非物理真空缝**:
`ensure_dielectric_substrates` 在有 carved ground 时把衬底顶面下移 1µm
(`CARVED_GROUND_SUBSTRATE_GAP_SI`), 为躲 OCC 共面 fragment 失败。金属底与硅顶之间
多出 1µm 真空 → 近表面共面耦合被削弱 → 全矩阵偏低。two_pads (无 ground → 无 nudge)
不受影响, 故一直正确, 反衬出 qm4q 的差异。

**正解 (不塞缝, 正经修数值障碍)**:
1. `_gmsh_geo_source`: 删 nudge → 衬底顶 z=0, 金属共面坐硅上 (物理精确)。
2. `_gmsh_layers.fragment_everything`: fragment 前把整模型 dilate 回 µm、fragment 后回米
   → 共面 fragment 在整数 µm 坐标下稳健 (米制下会 "Boolean fragments failed")。
3. `_gmsh_mesh.generate_mesh`: 3D 默认 HXT (Algorithm3D=10) → 划得动共面界面
   (Delaunay 会 "PLC Error: segment and facet intersect")。
判定实验: 0 缝 + 各 3D 算法, 仅 HXT(10)/Frontal(4) 成功。

## 另外两处修复
- `carve_conductors`: ground + 导体改**两步 cut (先 ground 后导体)**。一次性 cut 时 OCC 把
  穿过 CPW 缺口的 conn_b/c/d 漏切 (原地变真空, 质量 = 金属体) → 只解 3/6 端子的错误矩阵。
- `carve_conductors`: 切碎的真空 fuse 回单体 (保留薄片会留共面重复面 → 3D mesh "overlapping facets")。
- 新增 `solver.outer_boundary: ground|open` (默认 ground; open ≈ 自由空间 FarField, 对齐 Elmer)。
  贯穿 schema/parsers/palace_adapter/geo_build。qm4q 用 open。

## 验证结果 (order-2 + open + 共面)
6×6 自电容 vs 参考 Elmer 7×7 同名对角:
- pad_top 104 / pad_bot 108 → **−5.5% / −5.9%** (主焊盘=qubit 岛, 最关键, 吻合到 5%)
- conn_a..d +13~17% (引线尖端贴近 airbox 边界, 开放边界镜像过耦合; airbox 加大可降)
- 互容 pad_top-bot −33.6 (ref −36), 结构完全正确 (对角正/非对角负/对称)。
逐步效果 (同几何): ①1µm缝+接地 −30% → ②共面+接地 +41% → ③共面+开放 order-1 +44%
(order-1 欠收敛, 同设置两次网格 74 vs 91) → ④共面+开放+**order-2** −5.5% (收敛, 最终)。
三个杠杆 (去缝/开放边界/order-2) 缺一不可。

## 残差 (已理解, 非几何错)
- 主焊盘 −5.5%: Palace(电荷通量) vs Elmer(能量) 跨求解器 + 残余收敛。
- 连接器 +17%: Palace 静电无真 FarField, 开放边界(Neumann)对近边界引线过耦合。
