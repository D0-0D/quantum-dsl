# Session 2606300056 — build 结果归档:输入副本 + 文件指纹清单

## Goal
用户需求:生成 build 结果时,把 `meta.yaml` 和 `.geo` 也复制一份到结果文件夹;再新建一个文件,
记录各文件的指纹(sha256)与生成/修改时间——覆盖原始输入(meta + geo)+ 全部产物
(gds + json + msh + results.yaml)。

## Locked decisions(与用户确认)
- 清单文件名/格式:**`chip.manifest.yaml`**(YAML,与现有 `chip.*` 产物命名一致)。
- 输入副本命名:**保留原始文件名**(如 `qm4q_transmon_cell.meta.yaml` / `.geo`);
  `cells:` 自动生成的 `*.elaborated.geo` 本就在 out_dir 内 → 不重复拷贝、只登记。
- manifest 与 `chip.results.yaml` 的 `provenance` 块**并存、职责不同**:manifest = 文件夹级
  文件清单;provenance = results 自身溯源。不改 results schema。
