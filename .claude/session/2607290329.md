## 3. 与 spec 文本的偏离（都是刻意的）

| # | spec | 实际 | 理由 |
|---|---|---|---|
| 1 | `extract.blocks[].junction:`（单数） | **`junctions:` 列表** | 4.05「每 cell 一个结」只是最简情形；一块多结（sung、coupler+qubit 同块）必须能表达 |

## 4. 未做 / 欠账

- **P1-G / P1-H / P2-I / P2-J / P2-K 全未做** —— 本次范围是 P0（用户明确指定）。
  P1-H（精确 CPB 对角化）是把 χ 对老 LOM 的 −16.1% 里那 −8.33% 关掉的唯一途径。
- **§7 的 S2 live Palace 护栏没跑** —— 需要一个 pocket 互不相连的设计（`chip_layout` 的孔已合并，
  `keep_all_subtractive` 在它上面是 no-op）。目前 S2 由**几何层**的点覆盖断言 + 面积/孔数
  量化守着（`test_geo_block.py`），**没有**「两解对地电容比值」这条实解证据。
- **sung 的分块误差没能干净测量**（见 §2）—— 卡在 issue #22（整片 order 2 解不出来）与
  #18/#26（网格收敛）。可信数字来自 `two_pads` 的 +1.03%。
- `AssembledSystem.as_capacitance_result()` 自己不设 `source`（默认 `"solved"`）；由 `geo_build`
  用 `dataclasses.replace` 改写成 `assembled:<来源集合>`。若将来有第二个调用方，那个改写要跟着走
  —— 更干净的位置是 `as_capacitance_result()` 本身接一个参数。
- **拼装层的 R2 警告在 4.05 上会误报**：`coupling` 是合法的「共享、无结、未 force-keep」节点，
  触发「未被任何 subsystem 或 nodes_force_keep 引用」的 warning。消息同时给出两种读法，
  `nodes_force_keep` 可消音。判据本身来自 spec §11 R2，没改。
- `_units` 在 import 时就 `from qiskit_metal...`，而 `qiskit_metal.analyses.__init__` 饿加载
  `lumped_capacitive` → 那 3 个 χ 交叉验算测试的 `importorskip` 在本机**永不触发**，是纯保险丝。
