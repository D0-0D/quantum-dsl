## 结果 (H01 块 vs SI §D; 本机 Palace 0.16, 8 rank, 100/4 order 2 = 105 万未知量, 573 s, 单网格未收敛)
SI 节点 1,2 = Q0 半盘 (2 靠条), 3 = 条 (+两爪), 4 = 五边形, 5,6 = Q1 半盘 (6 靠条); 本机 Q01_a / Q11_b 是靠条的半盘。

- **系统性**: 对地全部偏大 (细条 / 板 ×1.45, 半盘 ×1.1–1.2), 互容全部偏小 (×0.4–0.5) —— 同一个方向 = 载片地比 SI 模型里的**更近**。
  按平行板 C04 ∝ 1/d 反推 SI 的 d ≈ 5 × 238/165 ≈ 7 µm (SI 说 bump ~10 µm 未压合; 5 ± 0.4 是另一篇实测)。d 单量拟合 (几何稿 §5.2 的方案) 是 phase 2 首项。
  互容除 d 之外还吃 10–15 µm 级间隙 (照片 ±30–50%) 与爪角跨 —— C23 ×0.49 不能全归 d。
- Q–Q 直接互容 ≤ 0.013 fF (SI 网络设为 0, 与之一致); 半盘–五边形 0.3 / 1.2 fF。
- **哈密顿量** (`solve_circuit_model`, 3 个浮动结, E_J 12.4 / 21.1 / 12.4 GHz):
  E_C(q) = **220 MHz** (SI 自身闭合 209, 设计 185, 实测 α −179～−200), E_C(c) = **154 MHz** (SI 闭合 171),
  g_qc = **66.8 / 65.0 MHz** (SI 闭合 71, 设计 90), g_qq = **3.7 MHz** (SI 闭合 9.1, 设计 5); f01(q) 4.45 GHz, f01(c) 4.95 GHz。
  → 单个 C 差 ±50% 的两组偏差在 E_C / g 里大半抵消, 派生量落在 SI 自身 10–20% 闭合缝之内; 这是量级检验, 不是命中。
- **d = 7 µm 复算** (同网格配方, 568 s): 对地 C 半盘 124 / 116 (SI 137 / 119, ×0.90–0.98), 条 162 (×1.22), 板 190 (×1.15) —— d 解释了对地项;
  **互容几乎不动**: C12 11.2 / C34 12.1 / C23 13.4 (仍 ×0.43–0.52) → 互容的一半缺口不是 d, 是几何/口径 (缝 70、盘–爪 12、条–板 75 都是照片 B/C 级量;
  或 SI 的电磁模型口径不同)。哈密顿量 d=7: E_C(q) 259 / E_C(c) 181 MHz, g_qc 85 / 82.5 MHz, g_qq 5.9 MHz (设计 185 / 90 / 5; 实测 α −179～−200 反而更贴 d=5)。
  两档 d 夹住了 SI 的对地项, 夹不住互容 —— phase 2 先做缝宽 / 间隙灵敏度再谈 d 拟合。产物 `.claude/chen-evidence/H01_d{5,7}_*`。
