  坑: 原型里一阶式子误用 λ₀ = 1（应为 λ₁ = √2）, DRAG 看起来只好 4×; 改对后 σ = 1.5 最优 1.13e-6。
- **实验室系不收敛**: SuperGrad `Evolve`（中点 expm）CR 240 ns 60 步/ns 酉阵差 0.07 → 改相互作用绘景; 但纯中点取相位时反旋转项混叠, CR 5 能级 50 步/ns 泄漏差 20%、
  误差差 2× → sinc 步内求积, 50 步/ns 收敛 <1%。交叉验证: 与 SuperGrad 实验室系 Evolve（2000 步/ns）差 < 2e-3（只差全局相位——原型里一度以为差 0.47, 是基态能零点）。
- **OpenBLAS 线程争抢**: jax CPU expm ≤ 20 维 ~20 µs/步, ≥ 24 维 12 ms/步（CR 一次演化 145 s, 第一版冒烟卡 20 min）; 单线程 BLAS 60–80 µs。`threadpool_limits` 包住整段。
- **反向梯度贵**: 16 维 × 1.4 万步, SuperGrad LCAM / 前向模式都 ~150 s/次梯度（前向 0.4 s）→ CR 只标幅度（相位 / 小失谐被局域补偿吸收, 实测相位 0 与 π 同误差）。
- **ZZ 闭式**: 教科书 2g²(α₁+α₂)/((Δ+α₁)(Δ−α₂)) 假定 λ² = 2; transmon λ² ≈ 1.90 → 远失谐对偏 4.3%; 自推非 RWA + 精确 λ 全式 0.05%（测试锚）。
- **闭环实跑**（真 Palace 8 rank）: `build(xmon_pair)` 98 s; `tune(xmon_pair_tune)` 7 次 FEM 收敛（与 10-14 逐位同）+ 终版门 = 494 s。
