## 0. 为什么重做（2026-09-18 反馈）

v1 的蛇形是 `LIB_CPW_MEANDER` 闭式的**旋转**：轴 = Dubins 中间直段（方向由两口连线决定），腿等长、关于轴对称、一次性放在直段中央。反馈四点：

1. 蛇形的**轴向**只看两口连线，不看可用区域。区域是轴对齐矩形，斜着放浪费四角，也不是版图常规（横平竖直）。
2. **腿必须等长**：区域两侧余量不同时只能按小的一侧取，大的一侧空着。
3. **哪里折、哪里直**没有决策：先弯哪侧只试两种，摆放固定居中，腿数取最小可行；没有「按余量放腿」的概念。
4. 不能指定**横平竖直 / 特定方向**。

外加一条演示需求：**被可用区域限制时绕路**。§4.3 说明单个矩形挡不住最短骨架；用户拍板 **`region` 可以是矩形拼接（并集）**，缝就是障碍。

## 1. 需求

保留 v1 全部硬约束：G1 连续（直段 + 半径 `R` 圆弧）、可定长（记账 ≤ 1e-9 相对）、`region` 含缝宽精确校验、端口面上一段直 CPW（`lead`）、
拒绝静默（任何装不下 / 非法输入都 raise 并说明）。新增：

| # | 需求 | 本稿的回答 | 章 |
|---|---|---|---|
| R1 | 轴向按可用区域定 | 骨架默认走**曼哈顿框架**（横平竖直，框架可转任意角 α）；蛇形放在骨架的某条直段上，腿垂直于它，长度由该处余量定 | §4.1, §5 |
| R2 | 腿可不等长 | 每个弯独立算**余量**（到 `region` 外框、到矩形之间的缝、到本条路其它直段的净距），腿长 = 余量按同一比例缩放；两侧可不对称 | §5.2, §5.4 |
| R3 | 折 / 直的决策 | 腿数取能装下目标长度的**最小值**；蛇形块沿直段扫摆放位置、试先弯左 / 右，取余量最大者；多余长度不够一个最小蛇形时 raise，不硬塞 | §5.3 |
| R4 | 可指定方向 | 步骤键 `axis:`：数值 = 曼哈顿框架角度（deg，`0` = 横平竖直，**默认**）；`free` = v1 的 Dubins 自由角 | §9 |
| R5 | 被挡住时绕路 | `region` = 矩形并集；骨架按（转弯数, 长度）排序逐条实现，出外框 / 进缝的丢弃，下一条接上（曼哈顿换模板、Dubins 换型） | §4.3, §10 |
| R6 | 一条直段装不下时多段分摊；拐角处两块不冲突 | 按各段容量比例把长度分到 2, 3, … 条直段，容量小的先放，先放好的块进后面块的障碍集；骨架与成品都过自身净距检查 | §5.6, §6 |
| R7 | 腿长随沿轴的可用宽度变（2×2 + 2×4 + 2×2 → 中间长腿）；弯半径可自动 | 余量逐弯**精确**算（含台阶角对半圆肩部的对偶射线）；`R: auto` = 最大可行整数半径 | §5.2, §5.7 |

**明确不做**：训练模型生成几何。几何必须闭式可记账、可测、失败可解释；模型至多能给候选排序，而候选集本来就只有几十条（§7），不值得引入数据与不确定性。

## 2. 术语

- **位姿** (x, y, θ)：点 + 行进方向（rad）。出发位姿 = from 口外法向；到达位姿 = to 口外法向 + π（驶入）。
- **引出**：两端各沿位姿方向直走 `lead` 的两段直线；下面一切在引出后的位姿 **s₂ → e₂** 之间做，记账含引出。
- **骨架**：s₂ 到 e₂ 的一条可行连接 = 直段 + 弧序列，不含蛇形。骨架里的直段是**轴段**候选。**转弯数** = 骨架里弧的个数（拆段前）。
- **蛇形块**：替换轴段中间一截的定长结构（§5.1）。**腿** = 垂直于轴的直线；**弯** = 腿间 180° 半圆；**块首 / 块尾** = 轴到第一 / 最后一条腿的 90° 弧。
- **余量** room：一个弯还能沿其外法向外推多远（§5.2）。
- **区域**：`region` 给的矩形并集。**外框** = 并集的包围盒（凸）；**缝** = 外框内不属于任何矩形的格子（把全部矩形的 x / y 边界拉成网格，逐格判）。
- **障碍**：缝 + 本条路自己的其它直段（含两段引出）。**净距** clr：中心线到自身其它直段中心线的最小距离 = **2R**
  （= 相邻两腿的间距；地宽同样是 2R − 总宽，与蛇形自身一致）。到缝与外框边的距离 = 总宽 / 2（它们是硬边界，不是另一条 CPW）。
- **总宽** width = 中心导体 w + 2·gap；所有含宽度的检查都用「中心线 + 总宽 / 2」。

## 3. 输入 / 输出

| 来源 | 量 | 说明 |
|---|---|---|
| 两个端口 `from` / `to` | 位置、外法向、宽、`leq`、层 | 只要求**同宽、同层**，不要求正对；朝向任意（非轴对齐的朝向由端弧转到框架方向，§4.1） |
| 步骤 `length:` | 目标总长 | 沿用现有机制（`fixed` / `quarter_wave` / `half_wave`，减两端 `leq` 后注入 `L`）；不给 = 最短骨架，无蛇形 |
| 步骤 `region:` | `[x0, y0, x1, y1]` 或 `[[…], […], …]` | 芯片坐标矩形或**若干矩形的并集**（可拼成 L / T / 回字），可选。全部原语含总宽 / 2 落在并集内：外框查取样点（直段两端，弧两端 + 弧内 0/90/180/270° 点 = 轴对齐矩形的精确极值）；缝查原语到格子的**精确距离** ≥ 总宽 / 2（直段–线段、弧–线段距离闭式，穿缝的直段两端都在缝外也抓得住） |
| 步骤 `axis:` | 数值 (deg) 或 `free` | 可选，默认 `0`。数值 = 曼哈顿框架角 α（mod 90°）；`free` = Dubins 自由角 |
| 模板参数 | `R` 弯半径或 `auto`、`n_legs` 总腿数（0 = 自动）、`gap` 缝宽、`lead` 引出 | `planner: cpw` 模板必须声明这四个（不变）。`n_legs: 0` 且给 `length:` 时必须给 `region:`（余量要有限）；多段分摊时 `n_legs` 是各块之和；`R: auto` 只对 planner 模板合法，解出的数字进 `subsystems.R_um` 并照常注入 |

**输出不变**：中心线原语序列 `("line", x1, y1, x2, y2)` / `("arc", cx, cy, R, a0, a1)`（每段 |a1 − a0| ≤ π/2，a0 → a1 增 = 逆时针），
按列注入 gmsh 列表变量 `_rt_n` / `_rt_kind(k)` / `_rt_p0..p4(k)`，`cpw_route.geo` 用 `LIB_CPW` / `LIB_CPW_ARC` 逐段画面，`cpw_length` 累加；
记账走现有 `outputs.length` 闭合。位姿恒等（芯片坐标规划），`mirror:` 对它无意义 → raise（不变）。

## 4. 骨架

### 4.1 曼哈顿框架 α（默认 α = 0）

方向集 **H_α = {α, α + 90°, α + 180°, α + 270°}**。

**端弧**（`_end_arcs`）：从 s₂ 的朝向 θ_s 转到某个 h₁ ∈ H_α，用一段半径 R 的圆弧，取转角较小的那一侧（左 / 右）；转角恰为 180° 时两侧都算（= 发夹）；
转角 > 180° 不算（另一侧更短，已覆盖）；θ_s ∈ H_α 时 h₁ = θ_s 是零弧。得 ≤ 5 个出发位姿 P₁（朝向 h₁）。到达端对称：从 h₂ ∈ H_α 转进 e₂ 的朝向，
弧倒着算，得 ≤ 5 个到达位姿 P₂（朝向 h₂，弧从 P₂ 起）。

**连接模板**（`_connectors`）：把 Δ = P₂ − P₁ 转到 h₁ = +x 的框架里得 (dx, dy)，r = (h₂ − h₁) mod 360° ∈ {0, 90, 180, 270}，σ = +1 (r = 90) / −1 (r = 270)：

| r | 模板 | 拐角（框架坐标） | 可行条件 | 自由参数取法 |
|---|---|---|---|---|
| 0 | 直 | — | dy = 0, dx ≥ 0 | — |
| 0 | Z | (m, 0), (m, dy) | dx ≥ 2R, \|dy\| ≥ 2R | m = dx / 2（居中）+ 格子中心 |
| 180 | U | (m, 0), (m, dy) | \|dy\| ≥ 2R | m = max(R, dx + R)（贴紧）+ 格子中心 |
| ±90 | L | (dx, 0) | dx ≥ R, σ·dy ≥ R | — |
| ±90 | 三折·顺向 | (m, 0), (m, q), (dx, q)，第三段 +x | dx ≥ 3R；σq ∈ [2R, σdy − R]（同向）或 σq ≤ −2R（反向） | m = (dx − R) / 2；同向 q 居中，反向 q 贴紧；m、q 再加格子中心 |
| ±90 | 三折·回头 | 同上，第三段 −x | m ≥ max(R, dx + 2R)；q 同上 | m 贴紧 + 格子中心 |

- 每个 90° 拐角 C（进向单位向量 a，出向 b）做圆角（`_fillet_path`）：切点 C − R·a 与 C + R·b，圆心 C − R·a + R·b，90° 弧，转向由 a × b 的符号定。
  两圆角之间的直段负长 → 该候选作废（= 0 时丢弃零长直段，两弧直接相接）。
- 骨架 = 引出 + 端弧 + 直段 / 圆角序列 + 端弧 + 引出，然后过区域检查（外框 + 缝），不过的丢弃。
- 自由参数不做连续搜索：候选 = 规则值（居中 / 贴紧）+ **region 网格各格子中心投影到框架里落在可行范围内的值**（2026-09-18 画廊里的回形区域暴露了只取贴紧值会把 U 的竖段放进中间的洞；加格子中心后中段能挑走廊走），由区域检查筛。天花板见 §13。
- 候选数 ≤ 5 × 5 × 6 = 150 条，多数在可行条件或区域检查处淘汰。

### 4.2 自由角（`axis: free`）

v1 的 Dubins CSC 四型（LSL / RSR / LSR / RSL，`_dubins_csc` 不变）；每条只有一个轴段（中间直段），转弯数 ≤ 2（零弧不计）。

### 4.3 骨架排序：**（转弯数, 长度）**，不是长度

- 曼哈顿单调路径长度 = |dx| + |dy| − k·(2 − π/2)·R，只差圆角数 k，**多拐一次反而更短**（每个圆角省 ≈ 0.43R）。按长度排会选三折而不选 L；
  设计者的直觉是「能一拐到就不拐三次」，所以先按转弯数。
- 同转弯数、同长度（曼哈顿里是常态：同 |dx| + |dy| 同 k 的路径长度完全相同）的候选分在**一组**，整组都做填充，取（腿数, −余量）最优者；
  一组里有任何可行解就不再看后面的组（骨架先定）。
- **不按「腿最少」排骨架**：骨架越长剩余长度越少腿越少，会系统性偏向绕远路。骨架先定，填充只在骨架的直段上做——与 qiskit-metal /
  gdsfactory「先走线、再在最长直段补长度」的惯例一致。
- **R5 的几何事实**：单个矩形是凸的，包含两口位姿就包含它们之间的一切单调路径，也包含最短 Dubins 型的凸出（它总是朝目标转）。
  所以单个矩形几乎不会把最短骨架挡掉再让次短的过——它只影响填充（腿伸多长、往哪侧、块放哪）。**绕路来自拼接出来的缝**：
  L 的拐角落进缝 → L 淘汰 → 端弧 + L + 端弧 / 三折（3 转弯，同长）接上，由填充定谁胜。演示按此设计（§10）。
- 显式 `n_legs` 在第一组装不下时同样落到下一组：`n_legs` 的语义是「恰好这么多腿」，骨架随之变长是可见的、可解释的。

## 5. 填充（给了 `length` 时）

### 5.1 蛇形块的结构与记账（`_meander_parts`）

在轴段 A → B（单位切向 t，左法向 n，长 S）上放 n 条腿（n ≥ 2），块起点距 A 为 ℓ_in ∈ [0, S − 2Rn]，块占轴向 [ℓ_in, ℓ_in + 2Rn]，块后剩余直段 ℓ_out = S − 2Rn − ℓ_in：

```
            腿1   弯1   腿2   弯2   腿3                    弯 k 在侧 σ_k = σ₁·(−1)^(k−1), 半圆圆心 (c_k, σ_k·u_k),
     +n ↑         ╭──╮        ╭──╮                       c_k = ℓ_in + 2kR (轴向), k = 1..n−1
        │   u₁    │  │  u₃    │  │                       腿 k 在轴向 ℓ_in + (2k−1)R, k = 1..n
   轴 ──┼──ℓ_in──╯  │        │  ╰──ℓ_out──►  t          块首 / 块尾 = 90° 弧, 半径 R, 圆心在轴旁 R 处
        │           │  u₂    │
        │           ╰────────╯                           u₂ > u₁: 下侧余量大, 腿更长 (R2)
```

- 块首 90° 弧把轴转向 σ₁·n，落在法向 σ₁R 处；腿 1 从 σ₁R 走到 σ₁u₁（长 u₁ − R）；弯 1 = 圆心 (c₁, σ₁u₁) 的半圆，落到法向 σ₁u₁、朝 −σ₁n；
  腿 2 从 σ₁u₁ 走到 −σ₁u₂（长 u₁ + u₂）……腿 n 从 σ_{n−1}u_{n−1} 走到 σ_{n−1}R（长 u_{n−1} − R）；块尾 90° 弧回到轴上。
- **每个弯有自己的 u_k ≥ R**（u_k = R 时相邻腿零长，两弧相接，允许）。u_k 全相等 = v1 / `LIB_CPW_MEANDER` 的等腿蛇形（amp = u）。
- 长度：弧总角 = 2·90° + (n − 1)·180° = nπ → 弧长 nπR；腿总长 = 2Σ_{k=1}^{n−1} u_k − 2R；直段 ℓ_in + ℓ_out = S − 2Rn。

  **M = S − 2Rn + nπR + 2Σu_k − 2R**，比原直段多出 **E = M − S = 2Σu_k − 2R + R(nπ − 2n)**。
  全部 u_k = R 时 **E_min(n) = R(nπ − 4)**（n = 2 时 ≈ 2.28R：最小的蛇形也要多出这么多，不够就装不下）。

### 5.2 余量 room_σ(c)（`_Run._room`，**精确**）

弯 k 在轴向 c、侧 σ 时，u 最大能取多少？基准半圆（u = 0、圆心在轴上）随 u 沿 σn 平移，求首次触界的 u。每种界都算**两个方向**的射线：
「半圆的极值点 → 界」（取样点 = 两端点、外顶点、落在弧内的 0/90/180/270° 点、对每条直线障碍其方向 β ± 90° 的点）和
「界的角点 / 端点 → 半圆」（点沿 −σn 射进**加厚半圆** `_ray_arc`，= 该点的圆盘首次碰到半圆曲线）。两者合起来对每种界都是精确的：

| 界 | 半圆 → 界 | 界 → 半圆 | 体–体 |
|---|---|---|---|
| 外框四边（内缩 width/2，凸） | 取样点 `_ray_exit_rect`（精确：极值点就是取样点） | — | — |
| 缝（格子外扩 width/2 = 圆角矩形） | 取样点射进两个方向的 slab（直边精确） | 四个角点射进「半圆 ⊕ width/2」（圆角部分精确） | — |
| 自身其它直段 / 已放好的块的腿（胶囊 2R） | 端点 + β ± 90° 点射进胶囊（直边精确） | 线段两端射进「半圆 ⊕ 2R」（端圆精确） | — |
| 自身的弧（端弧 / 圆角 / 别的块的弯，加厚 2R） | 半圆两端射进加厚弧 `_ray_arc` | 弧两端射进「半圆 ⊕ 2R」 | 两圆**外切**：半圆圆心沿 σn 到障碍弧圆心距 R + R_b + 2R 的首个根，接触点须同时落在两弧的角度范围内（内切不会先发生：等半径圆相离→相切→相交，弧的内部接触只能经过相切或端点） |

- 为什么要角点 → 半圆：台阶角落在弯的跨度 [c − R, c + R] 内时，半圆**肩部**（不是顶点也不是端点）先碰到角；只用取样点会把 R7 例子里的肩部放出界
  ≈ 24 µm（测试 `test_plan_cpw_legs_follow_the_region_profile_exactly` 锚定：3 腿最多 +841.16，取样点近似会说 +913）。
- 腿本身的扫过由两个端点取样的射线覆盖：弯 k 的端点 (c_k ± R, 0) 沿 σ_k n 的射线 = 腿 k / 腿 k+1 在该侧的整条扫过区间。
- 块首 / 块尾 90° 弧落在「轴 – 第一（最后）条腿」的三角形里，不在任何弯的扫过区里；它们与障碍的距离由成品的自身净距检查（§6）兜底。
- room < R → 该弯装不下 → 此 (n, ℓ_in, σ₁) 不可行，记下是哪个界挡的（外框边 / 哪条缝 / 自己哪一段 / 另一块）。没给 `region` 时外框项为 ∞。
- 余量只依赖 (c, σ)，与腿数无关：`_Run` 按位置缓存，摆放网格取 R/2 的整数倍（加居中与贴末端），所有腿数共用同一套位置 → 每条直段的余量只算一遍。

### 5.3 单段搜索（`_fill`）

对一条**非引出**直段 S ≥ 4R、要补的长度 X：

```
for n in (2 .. ⌊S/2R⌋)  或  (n_legs,) :
    X < E_min(n) → 记错误 "n legs add at least …", 结束
    for ℓ_in in {k·R/2 ≤ S − 2Rn} ∪ {居中, 贴末端}:
        for σ₁ in (+1, −1):
            room_k = room_{σ_k}(ℓ_in + 2kR), k = 1..n−1          # 缓存命中
            全部 room_k ≥ R 且 X ≤ E_max = 2Σroom_k − 2R + R(nπ − 2n)  → 可行, 记 slack = E_max − X
    有可行 → 取 slack 最大者 (并列取 ℓ_in 最靠中、σ₁ = +1), 结束 (n 已最小)
```

- 显式 `n_legs`：只试那一个 n。
- 没给 `region`（此时必有显式 `n_legs`）：room 只由自身给出，可能为 ∞ → 改用**等腿** u_k = U/(n − 1)，U = (X + 2R − R(nπ − 2n))/2，再逐弯查 u_k ≤ room_k；
  摆放并列 → 居中（退化一致性 §12 靠它）。

### 5.4 定长解（有 `region` 时）

**λ = (X − E_min) / (E_max − E_min) ∈ [0, 1]，u_k = R + λ·(room_k − R)**。

腿长随各自余量按同一比例缩放：余量大的一侧腿长（R2），λ < 1 时处处留边（余量按比例保留，不是「填满再截最后一腿」——那会让一条腿孤零零地短）。
外框关于轴对称且余量恒定（轴对齐）时 room_k 全等 → u_k 全等 → 与 v1 闭式相同（§12）。

### 5.5 输出与自检

按 §5.1 生成部件（长弧拆 ≤ 90°，零长直段丢弃），拼回骨架：引出 + 端弧 + … + [ℓ_in 直段 + 块 + ℓ_out 直段] + … + 引出。
最后对整条路径**重跑**区域检查、自身净距检查、记账与目标比对（≤ 1e-6）：按构造必过，不过即 raise `internal: …`（抓实现 bug，不静默）。

### 5.6 多段分摊（`_fill_runs` / `_fill_subset`）

一条骨架的可用直段 = 全部非引出、长 ≥ 4R 的 `line`。先**单段**：每条直段各跑 §5.3，候选按（腿数, −slack）排序，逐个做成品自身净距检查（§6），
首个通过的胜出。单段都装不下才**分摊**：

```
cap_i = 该段独立的最大容量 (对 n / 摆放 / 先弯侧取最大 E_max)          # 无 region 且不碰自身 → ∞
for k in 2 .. 段数:                                                      # 块少优先
    for 子集 sub (大小 k, 按 Σcap 从大到小):
        order = sub 按 cap 升序                                          # 容量小的先放: 占的地方少; 最大的最后吃精确余数
        rem = X; extra = []
        for idx, i in order:
            cap_j' = 剩余各段在 obstacles ∪ extra 下重算的容量           # 已放好的块是后面块的障碍
            Σcap' < rem → 子集失败
            share_i = rem                        (最后一段)
                    = rem · cap_i' / Σcap'      (其它)
            块_i = _fill(段 i, share_i, legs_i)  → 失败则子集失败
            extra += 块_i 的全部部件; rem −= share_i
        成品过自身净距检查 → 返回 (k, Σ腿, min slack)
```

- 每块内部仍是 §5.4 的比例缩放；块与块之间的份额按容量比例——余量多的段补得多，视觉上各块的填充比例接近。
- 显式 `n_legs` = **总腿数**：按容量（最大余数法）分给各段，每段 ≥ 2；分不开的子集跳过。
- 骨架同组比较改为（块数, 总腿数, −min slack）：一块能装下就不分两块；分摊只是装不下时的退路。
- 拐角处的冲突：先放的块的腿 / 弯 / 块首尾弧全部进后面块的障碍集（腿是胶囊、弯是加厚弧），所以相邻两条臂上的两块靠近共用拐角时，
  后放的块在那一侧的余量为 0 → 只能弯向另一侧或往后挪；再由成品自身净距检查兜底。
- 不做联合优化（份额与腿数一次分定，不回头调）；失败时报「runs #i, #j together reach at most +… um」。

### 5.7 `R: auto`（`auto_radius`）

可行性对 R **单调递减**：R 越小，骨架条件（dx ≥ R、|dy| ≥ 2R …）越松、直段能装的腿越多、`room ≥ R` 越容易、E_min 越小。所以唯一有意义的最优是
**能装下的最大 R**（弯越缓寄生越小、辐射越少）。在整数区间 [⌈width⌉, ⌊R_max⌋]（弯内径 ≥ 半个总宽；R_max 默认 = min(外框短边, 两口距离) / 2）
上二分，每步跑一次完整规划（≈ 10 步，demo 一对桨 0.1–0.5 s）。区间为空 / 最小半径也不行 → raise 带那次的原因。
给定 R 装不下时，失败信息先用同样的搜索（R_max = R − 1）算出能装下的最大 R 并提示「R <= N um would fit (R: auto picks it)」——只在失败路径上多跑几次。
编排器：`params: {R: auto}` 只对 planner 模板合法，`_plan` 解出数字后写回 params 再注入（模板参数 R 照常进 `.geo`），`subsystems` 记 `R_um`。

## 6. 自交与净距（`_obstacles` / `_self_clear`）

- **障碍集**（放块时）= 本条路全部部件（直段**与弧**，含引出）除去与轴段共端点的（相邻圆角 / 端弧 / 零弧相接的共线邻段——它们和轴段一起构成同一个弯，
  天然贴着）+ 已放好的其它块的全部部件。经圆角 / 端弧相邻的垂直直段保留：腿的轴向位置 ≤ S − R，到该直段 ≥ 2R，恰等于 clr 时按「开胶囊」(clr − 1e-6) 放行。
- **自身净距规则**（骨架与成品都查，`_self_clear`）：沿路间隔（前者终点到后者起点的路长）**≥ πR** 的任意两段原语，中心线距离须 ≥ 2R − 1e-6。
  间隔更短的两段是同一个弯的两侧（180° 弯两腿恰间隔 πR、相距 2R；90° 圆角两邻边相距 R√2），天然更近，不算冲突。曲率 ≤ 1/R 的 G1 路径上，
  路长 s ≤ πR 的两点距离 ≥ 2R·sin(s/2R)，所以 πR 是「同一个弯」与「回到自己旁边」的自然分界。
- 用途：① 骨架预筛——三折·回头 + 180° 端弧之类的候选会穿过自己的引出，v2 之前没有查（潜在自交）；两口相距 < 2R 同向时所有骨架被淘汰，
  报「segments #i and #j come within … um」；② 每个填充候选的成品检查——兜住块首 / 块尾弧等不在扫过区里的部件；③ 输出前的 `internal:` 自检。
- 距离算法全部闭式：直段–直段、弧–直段（圆–线交点 + 垂足方向上的圆上点 + 端点）、弧–弧（`_dist_arc_arc`：两圆交点落在两弧上 → 0；
  否则端点–另一弧与圆心连线方向上的圆上点对取最小——两圆曲线的距离驻点只在圆心连线上）。
- clr = 2R 的理由见 §2；不做成参数（升级路径：模板参数 `clearance`，默认 2R）。
- 不建模：本条路以外的东西（其它 `cpw_route`、别的模板）——它们的重叠由现有短路检查 raise，不会静默。

## 7. 复杂度（实测）

- 骨架：曼哈顿 ≤ 150 条（格子中心候选会翻倍），Dubins ≤ 4 条；每条区域检查 O(原语数 × 缝数) + 自身净距 O(原语数²)。
- 填充：每条直段的余量只算一遍（位置数 ≈ 2S/R × 2 侧，每个 ≈ (取样点 + 角点) × (4 边 + 缝 + 障碍) 次射线）；(n, ℓ_in, σ₁) 组合只是缓存查表。
  分摊时每一步给剩余各段重建 `_Run`（障碍变了）。
- demo 四条路单次 `plan_cpw` 4–160 ms；走廊两块 30 ms；回形三块 120 ms；`R: auto` 0.1–0.5 s（≈ 10 次规划）；失败路径 100–200 ms（含 R 提示的搜索）。
  `tests/test_route.py` 11 条 ≈ 100 s，其中 demo（四对 xmon 建网格 + R 自动）占大半。

## 8. 错误（全部 `QuantumDslError`，带步骤名与改法）

| 情形 | 信息要点 |
|---|---|
| 非法输入 | `R ≤ 0` 或非数值非 `auto`；`width ≥ 2R`（弯内径 ≤ 0）；`lead < 0`；`n_legs` 非整数 / 负；`region` 非 4 数 / 反向 / 并集里混进坏矩形；`axis` 非数值也非 `free`；`length ≤ 0`；两口重合 |
| 编排器 | `n_legs` 给了但无 `length:`；`n_legs: 0` + `length:` 但无 `region:`；`axis:` / `region:` / `R: auto` 用在非 planner 模板上；`mirror:` |
| 骨架全灭 | 每条：哪段出外框多少 µm（`leaves the region by`）/ 切进哪条缝多少（`cuts into the gap`）/ 自身两段太近（`segments #i and #j come within … um of each other (< 2R)`）|
| 填充全灭 | 每骨架：目标短于骨架（`shorter than this path`）；无 ≥ 4R 直段；`no single straight run holds +X um[, and splitting it across all k runs reaches at most +… um] — ` 后接前三条具体原因：多出 X 不够最小蛇形（`add at least`）；腿太多（`fewer legs`）；n 到 ⌊S/2R⌋ 仍不够（`reach at most`）；某侧余量 < R（`has only … beside the region edge / the gap … / the route's own segment #j / another meander block`）；成品净距（`its meander comes within … um of segment #j`）；子集失败（`runs #i, #j: …`） |
| 汇总提示 | 给定 R 装不下但更小的行 → 先给 `R <= N um would fit (R: auto picks it)`；再按情形：无 `length:` → 缩 R / 放大区域 / 换 `axis` / 缩 lead；显式 `n_legs` → 加减腿 / 缩 R / 放大区域 / 换 `axis`；自动 → 缩 R / 放大区域 / 改目标 / 换 `axis`（`every leg count 2..S/2R was tried on every straight run and on every split across runs`）；最多列 8 条骨架的原因，其余计数 |
| `R: auto` | 搜索区间为空（`search range is empty`：最小半径 ⌈width⌉ > R_max）；最小半径也不行（`even R = N um … fails: <那次的原因>`） |
| 内部 | 自检不过（区域 / 净距 / 记账）→ `internal:` 前缀 raise |

## 9. 语法与 API

```yaml
- {template: cpw_route, name: R2, from: Q3.RO, to: Q4.RO, params: {R: 40, gap: 6, lead: 60},   # R: auto = 最大可行整数半径; n_legs = 总腿数 (0 自动)
   length: {mode: fixed, L: 3000um},
   region: [[1680, -720, 2200, 100], [1680, -720, 2500, -300]],   # 一个矩形或矩形列表 (并集): 全部原语含缝宽落在其内, 缝就是障碍
   axis: 0}                                                     # 可选: 曼哈顿框架角 deg, 默认 0 = 横平竖直; free = Dubins 自由角
```

```python
plan_cpw(start, end, R, length=None, region=None, n_legs=0, width=0.0, lead=0.0, axis=0.0) -> list[tuple]
auto_radius(start, end, length=None, region=None, n_legs=0, width=0.0, lead=0.0, axis=0.0, R_max=None) -> float
# R: float | "auto";  region: [x0, y0, x1, y1] | [[…], …] | None;  axis: float (deg) | "free"
```

`_TPL_STEP_KEYS` 加 `axis`；`_PLANNER_PARAMS` 不变（`R n_legs gap lead`）。`axis` 与 `region` 是步骤键而不是模板参数：它们描述这一条路的环境；模板参数描述 CPW 本身。
`subsystems` 多出 `R_um`（`R: auto` 解出的数，或给定的 R）。

## 12. 退化一致性（回归锚）

两口正对共线、`lead: 0`、显式 `n_legs`、无 `region`（或外框关于轴对称且轴对齐）时：曼哈顿模板取「直」，room_k 全等（无 region 时走等腿分支），
u_k 全等 = v1 闭式的 amp，块居中 → 与 `cpw_meander` / `LIB_CPW_MEANDER` **逐段相同**（`test_cpw_route_degenerates_to_cpw_meander_when_ports_face`，14 段原语）。
外框不对称时腿按余量不等长，**有意**不再相同——这是 R2 的定义，不是回归。

## 13. 限制 / 天花板（`route.py` 顶部 `# ponytail:` 同步）

- 区域 = 矩形并集，不做多边形（升级：多边形边当直线障碍，外框检查改 point-in-polygon，接口不变）。
- 曼哈顿连接模板到三折为止（≤ 3 个内部拐角 + 两端弧）；自由参数只试规则值 + region 格子中心，不按填充余量优化。
  升级：在 region 网格（矩形边界 ± R、格子中心线）上做最少转弯 Dijkstra，得任意折数的骨架，再圆角、再区域 / 净距筛——迷宫式走廊才需要。
- 多段分摊按容量比例顺序放，不做联合优化（份额一次分定；后面的块装不下就换子集，不回头改前面的）。
- `R: auto` 假设可行性对 R 单调（成立于一切已知情形；若某处不单调，二分给出的仍是可行解，只是不一定是最大）。
- 不同 `cpw_route` 之间不互避（重叠由短路检查 raise）。
- 不做 CCC 型 Dubins、不做 taper / 变宽、`lead` 两端同长（分端 `lead_from` / `lead_to` 留 backlog）。

## 15. 已定的五个决定

1. **默认 `axis: 0`（横平竖直）**，v1 的 Dubins 变成 `axis: free`。理由：版图常规、`region` 本就是轴对齐矩形。
2. **障碍用 `region` 矩形拼接（并集）表达**（用户拍板），不另加 `keepout:`：一个概念、一套检查（外框 + 缝）。
3. **净距 clr = 2R 固定**，不加参数。
4. **骨架排序（转弯数, 长度），填充排序（腿数, 余量）**，骨架先定；同组骨架由填充定胜负。
5. **腿长按余量比例缩放**（λ），不是「填满再截最后一腿」。

## 16. 调试画廊（临时工具）

`tools/route_gallery.py`（不进契约 / 文档地图）：30 个场景直接喂 `plan_cpw`（含走廊两块 / 回形三块 / 窄–宽–窄台阶 / 偏置台阶 / 口太近 / 12 腿分摊 / `R: auto` 两例），每个一张 PNG——蓝框 = region 矩形，红底 = 拼接留下的缝，箭头 = 端口位姿，右上角罗盘 = `axis`，细灰 = 最短骨架，红 + 灰 = 定长后的 CPW 中心线与两边，左上角参数（`R: auto` 时显示解出的 R）/ 腿数 / 转弯数 / 耗时，失败场景把报错画在底部；`--overlay` 给 build 出的 demo GDS 图叠每条 `cpw_route` 的 region 框与 axis 标注。输出到 `build/demo/route_gallery/`（gitignore）。

## 17. 与手写 `.geo` 的分工

| 要画的 | 用什么 |
|---|---|
| 两口正对共线的定长蛇形 | `cpw_meander`（局部坐标模板，仍保留，退化一致性的锚） |
| 两口**不正对**、区域（可拼接）内、可定长、横平竖直或自由角、G1 连续的 CPW | `cpw_route`（本稿） |
| 其它任何形状（多边形区域、变宽、非 CPW 连接、多路互避） | 手写 `.geo` 步骤 + `connect:`（grammar §4.1；例 `chen_2025_3x3_hand`） |

自动布线不取代手写：它只回答「两口之间、区域内、定长」这一个问题，答案是直段 + 圆弧序列；用户看不顺眼随时可以把同一对端口改成手写路线。
