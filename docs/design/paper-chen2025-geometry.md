## 0. 结论先行

1. **能排 3×3。** 器件本身就是 72 比特方格阵列的一小块：每个比特圆盘四周 N/E/S/W 各一个耦合器"爪"，
   SW 方向一个读出爪；照片里相邻单元的耦合器条、五边形、读出焊盘都在，**互不相撞**。3×3 = 9 比特 + 12 耦合器
   + 9 读出焊盘，晶格常数 **1383 µm**，加读出焊盘外伸约 4.5 × 4.5 mm。
2. **几何全部只能从照片量**（正文 / SI / arXiv 均无任何 µm 尺寸），比例 **2.50 µm/px**（0.5 mm 标尺 = 200 px），
   每条边 ±1 px = ±2.5 µm。大结构（盘径 390、间距 1383、条宽 30、五边形 378）可信到 1–3%；**10–15 µm 级间隙只有
   ±30–50%**；SQUID / 细引线在分辩率以下。
3. **SI §D 给了整个 QCQ 系统的 11 个电容值（6 金属板 + 地，flip-chip 电磁仿真）**——这是比 Sung PRX 好得多的锚：
   我们的 FEM 直接出同一张 6×6 Maxwell 矩阵逐项对比，不必绕经 E_C。再往上一层，SI 给设计值 α = −185 MHz、
   g_qc = 90 MHz、g_qq = 5 MHz，Table SI 给 12 只比特实测 α = −179～−200 MHz。
4. **最大未知量是 flip-chip 真空间隙 d**：地平面在载片上，隔 d 面对所有金属，C_0i ∝ ~1/d。SI 只说"In bump 约 10 µm 高"，
   BAQIS 同工艺论文（arXiv:2106.00341）实测键合后 **5 ± 0.4 µm**；用 SI 的 C 值反推也落在 ≈5 µm。验证时把 d 当**唯一
   标定旋钮**：用一个 C 定 d，其余 10 个是预测。
5. **管线侧不用新代码就能装下这个物理**：`airbox.top_um = d` + `solver.outer_boundary: ground`（默认）就是载片地平面；
   蓝宝石各向异性、蛇形读出腔、载片走线是次级修正。

## 2. 论文与 SI 给了什么（可当真值的数字）

### 2.1 器件与工艺（正文 §"Implementing…"、SI §D–§E）

- 72 比特方格阵列，**每个比特与耦合器都是可调频的浮动（floating）transmon**（ref. 21）。
- **flip-chip**：比特、耦合器、读出谐振腔在顶片（**200 nm Ta / 预退火蓝宝石**）；控制线与读出馈线在载片
  （高阻硅）；载片上有回流空气桥；**In bump 约 10 µm 高**，80 N 键合。⇒ 顶片上**没有整片地平面**（照片里深色底就是裸蓝宝石），
  地主要是载片那一面。
- 结：Al/AlOx/Al Dolan 桥，双角度蒸发。

### 2.2 集总电容网络（SI §D，Fig. S4，电磁仿真值，fF）

节点：1、2 = Q0 两半盘；3 = 耦合器（与两比特都耦合的那块 = **横条**）；4 = 耦合器另一板（= **五边形**）；5、6 = Q1 两半盘；0 = 地。

| 对地 | 值 | 互容 | 值 |
|---|---|---|---|
| C01 | 137 | C12（Q0 两半盘） | 23 |
| C02 | 119 | C34（条–五边形） | 28 |
| C03（条） | 133 | C23（Q0 半盘 2 – 条） | 26 |
| C04（五边形） | 165 | C36（条 – Q1 半盘 6） | 26 |
| C05 | 137 | | |
| C06 | 119 | C56（Q1 两半盘） | 23 |

Maxwell 矩阵对角 M_ii = C_0i + Σ互容，非对角 = −互容（SI 原话）。**注意 SI 网络里没有 Q0–Q1 直接互容、没有四周其它三个
耦合器的爪、没有读出爪**——它是"孤立 QCQ"的仿真，我们的 FEM 若把周边结构画进去，对角项会系统偏大，比较时要么同样
只画 QCQ，要么把周边当地算进 C_0i。

## 3. 从照片量出的几何

### 3.1 方法

Fig. 1a 顶部照片，600 dpi 渲染后 1185 × 630 px（照片有效区 1144 × 592 px）。按颜色分 6 类（裸蓝宝石深灰 / Ta 浅紫 /
蓝 / 红 / 绿假彩 / 白），白色 0.5 mm 标尺 **200 px（各行 197–200）→ 2.50 µm/px（±0.5%）**，视场 2860 × 1480 µm。
圆盘用边界点最小二乘拟合圆（残差 3–4 px，假彩边缘不齐）；缝宽取垂直于缝方向的剖面；爪、间隙用从圆心出发每 5° 一条射线的
径向游程；条、五边形、焊盘用连通分量 bbox + 逐行 / 逐列延伸。标注图：`paperB/fig1a_annotated.png`。

## 4. 阵列拓扑：排 3×3 要什么

**照片里能直接看到的**（不是推断）：

- 每个盘四周 **0° / 90° / 180° / 270°** 各一个耦合器爪，爪中心各接一条 30 µm 宽的条：E 向是绿色耦合器，N / S / W 三条
  伸出视场（W 条 780 µm 后接左邻耦合器的五边形 + SQUID，在照片左缘）。⇒ **方格晶格、四近邻、耦合器沿晶格轴**。
- Q0 下方 (x = 400 px) 与 Q1 下方 (x = 953 px) 各有一个朝 +x 的五边形 + SQUID 接在竖条上 → 纵向耦合器的样子（表 #12）。
- 照片顶部三块 45° 读出焊盘（中心 x ≈ 592 / 1145 px，y ≈ 39 px），间距 553 px = 同一晶格常数。
- SI Fig. S6a 画的是同一方格晶格（转了 45° 画，次近邻画成水平相邻）；Table SI 用了 Q0–Q9 一条 10 比特链 + Q11–Q12 一对。

**推断（照片信息不够，标出）：**

- N–S 晶格常数 = E–W 的 1383：依据是纵向耦合器五边形距上方比特 540 = 横向的 540/843 分法，若纵向间距不同则耦合器条长
  不同、SI 就不会只给一组 C。
- 上一排比特的读出焊盘位置与本排不同（本排在比特 SW 651 µm；顶部那排焊盘若也属 SW 45° 则距其比特 1278 µm，或者上下
  排镜像）。**照片定不了**；3×3 自己设计时统一取 SW 651 即可——照片已证明这个放法与四周所有结构无碰撞。

**排 3×3 需要的 cell 与朝向**（相对每个比特圆心，y 向上，单位 µm；数字全部来自表 3.2）：

| cell | 个数 | 放置 |
|---|---|---|
| 圆盘比特（两半盘 + 缝 −45° + 中心 SQUID + 4 耦合器爪位 + SW 读出爪位） | 9 | 晶格点 (i, j)·1383 |
| 横向耦合器（条 y = 0，x ∈ [200, 1183]；五边形中心 x = 843, 底 y ≈ +80，尖朝 +y；SQUID 在底边中点） | 6 | 每对 E–W 邻居 |
| 纵向耦合器（条 x = 0，y ∈ [−200, −1183]；五边形中心 y = −540，底 x ≈ +80，尖朝 +x） | 6 | 每对 N–S 邻居 |
| 读出焊盘（45° 方 530，中心 (−460, −460)，λ/4 蛇形 + 细线到读出爪） | 9 | 每比特 |
| 边缘比特的空爪 | — | 3×3 外圈比特有 1–2 个方向没有邻居：爪留着（照片里爪属于比特还是耦合器看不出——爪与条同色同连通，**推断爪属于耦合器**，SI 的 C23 = 26 fF 是"半盘–条"互容，与爪属条一致）。无邻居就不画耦合器、也不画爪 |

**碰撞核算**（用表中数字，单个比特原点）：读出焊盘 x, y ∈ [−835, −85]；本比特纵向耦合器五边形 x ∈ [80, 380] → 不撞；
左邻横向耦合器五边形 x ∈ [−729, −351]、y ∈ [80, 380] → 不撞（焊盘 y ≤ −85）；左邻纵向耦合器五边形 x ∈ [−1303, −1003] →
与焊盘左顶点 −835 隔 168；下邻 N 条 x ∈ [−15, 15] → 与焊盘右顶点 −85 隔 70。**全部与照片一致**（照片就是这个周期结构的一段）。

芯片外廓：2×1383 + 390 ≈ 3.2 mm 方 + 外圈读出焊盘再外伸 835 → ≈ 4.5 mm 方（不含边缘耦合器）。

## 5. 排出来能不能验证

### 5.1 分层清单

| 层 | 验什么 | 数据够不够 | 现有管线 |
|---|---|---|---|
| **几何** | 岛数（9 比特 × 2 + 12 耦合器 × 2 = 42 浮岛 + 9 读出焊盘）、面积（半盘 4.7×10⁴、五边形 7.9×10⁴、条+爪 3.9×10⁴ µm²）、无重叠、最小间隙 ≥ 10 µm、Physical 名齐 | **够**（全部来自本文表 3.2） | `build(solve=False)` + `<stem>.gds.png` 预览就能做；单元格周期性可用 3×3 与 1×2 面积差断言 |

### 5.2 电学层怎么读数（避免重蹈 Sung 的坑）

- **模型范围要与 SI 一致**：SI 的 QCQ 仿真只有 6 块金属 + 地。我们若画进四周其它三个耦合器的爪、读出爪，它们对
  C_0i 的贡献要么并入地（保守：把它们标 `ground::`），要么单独成岛后 Schur 消掉（`assemble` 路径已有）。两种口径
  都算一遍、差值就是"周边结构效应"，别混进 d 的拟合。
- **d 的拟合只许用一个量**，其余全部作预测报出；d 的可信区间外部锚是 5 ± 0.4 µm，若拟合值跑出 3–8 µm 说明几何或
  口径有错，不是 d。
- **蓝宝石 ε**：各向异性（⊥ 9.4 / ∥ 11.5）。地平面隔 5 µm 真空，衬底侧贡献是次级项，先用标量 10 跑，再用 9.4 / 11.5
  两端做灵敏度（预计对 C_0i 影响 <5%）。Palace 的 `Permittivity` 接受张量，需要时可上。
- **SI 网络的闭合度算法**（可复算）：M 按 §2.2 组装 → C = SᵀMS（S 为 S16 的 Σ/Δ 变换）→ E_Ck = e²/2·(C⁻¹)_{ΔkΔk}，
  E_ij = e²·(C⁻¹)_{ΔiΔj} → g_ij = 4E_ij·[E_Ji/(32E_Ci)]^{1/4}[E_Jj/(32E_Cj)]^{1/4}，E_J 由 ω = √(8E_CE_J) − E_C 反解。
  用 e²/2h = 19.3706 fF·GHz 得 209 / 171 MHz、71 / 9.1 MHz（§2.3）。**我们的 C 矩阵进同一段公式，才与 SI 同口径。**

### 5.3 只能做量级检验或做不了的

- g_qc、g_qq：只有设计值，且 SI 自身闭合差 20–80%。
- 耦合器 SQUID 的 E_J1/E_J2、磁通甜点、g(Φ_c) 曲线：没有磁通轴。
- 读出腔频率与 χ：蛇形几何在分辩率以下，馈线在载片。
- 10–15 µm 级间隙的绝对值（±30–50%）→ 互容 C23 / C36 / C12 的预测误差会被这个主导；应在报告里先做一次
  gap ±3 µm 的灵敏度再谈"命中"。
- 比例标定的绝对精度：标尺是作者事后画的矢量，±1 px / 200 px = 0.5%，比 Sung 那张（±1.5%）好。

## 6. 给 A 路（component library）的几何事实

只列 A 路设计 cell 时必须知道、且本文已确证的事实，不做设计：

- 比特 = **圆盘 D 390 切一条 70 µm 缝成两半**，缝向对晶格轴 −45°，SQUID 在圆心。四个爪位在 0/90/180/270°，读出爪位 225°。
- 耦合器 = **条 30 × 890 + 两端弧形爪（厚 40，±20°，随盘径 195 + 间隙 12 共形）+ 五边形板（底 378 × 高 300，45° 屋顶）
  + 条–板间 SQUID（缝 70）**；五边形偏置在离一端比特 540 处、在条的一侧；横 / 纵两种朝向差一个镜像（表 #11–#12）。
- 读出 = 45° 方形地焊盘 530 内嵌 λ/4 蛇形 + 细线到读出爪；焊盘中心在比特 SW 651 处；焊盘靠 In bump 接载片地。
- 物理层：**顶片无地平面**；地 = 载片平面，隔 d ≈ 5 µm 真空；蓝宝石厚 ~430–500 µm 在金属另一侧。
  ⇒ `.meta.yaml` 的 `airbox.top_um` 就是 d，是这套 cell 的物理旋钮，不是网格参数。
- 全部尺寸的可信度见表 3.2 的置信列；≤15 µm 的量在 cell 里应当是**显式参数、默认值标"照片估计"**。
