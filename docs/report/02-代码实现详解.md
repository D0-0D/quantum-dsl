## 0. 全局心智模型（先记住这 5 句）

1. **两层输入**：几何在 `.geo`（微米），物理参数在 `*.meta.yaml`（材料 / 域 / 网格 / 求解器 / 图层映射 / 结）。
2. **两路输出**：`.geo` 同时分叉成 `chip.gds`（版图，µm 逐字）和 `chip.msh`（3D 网格，**也是 µm**）→ Palace 解电容。
3. **一个绑定 key**：每个面的 Physical 名 `role::layer::component::primitive`，**component 段 = 电学岛**，所有阶段靠它对齐。
4. **JJ 是集总元件**：只画进 GDS（`jj` role），**不**作为导体网格化（否则把焊盘短路）。
5. **导体是零厚度片，不是挖空的腔**：金属面直接印进衬底 / 真空界面，Palace 在这张内部面上钉电位（Terminal）。
   没有布尔减，所以没有 v3 的那一整类几何失效。

> 两个最容易被问的「为什么」：
> - **为什么全程微米？** GDS 给流片（gdstk 习惯 µm，`unit=1e-6`）；网格也写 µm，Palace 端 `Model.L0 = 1e-6` 声明单位。
>   仓库里**只有这一个换算点**（`palace.py:76`）。v3 曾用 `occ.dilate` 把模型缩放到米——那是全量几何重建，会静默损伤几何。
> - **为什么算电容矩阵就够？** 工作频率 GHz、波长 ~cm ≫ 版图 ~100 µm，准静态成立 → 静电求 C → 电路量子化得哈密顿量。

## 1. 单位（`units.py`）

**做什么**：两把尺——长度进来变 µm，物理量进来变 SI。


**拆解**：`parse_length(5)` = 5 µm，`"0.5mm"` = 500；`parse_quantity("10nH")` = 1e-8 H，但 `parse_quantity("10")` **拒绝**——
裸数没有量纲。`True` 单独挡掉（`True == 1`）。**坑**：单位表匹配顺序——`GHz` 若先匹配到 `H` 会解成 "G·亨利"，所以按最长后缀试。

**gmsh session 管理是这里最大的坑**（`_gmsh.py:31-54`）：

```python
@contextlib.contextmanager
def geo_model(path):
    import gmsh
    if not gmsh.isInitialized():
        gmsh.initialize()                             # 只初始化一次, 从不 finalize
    name = f"qdsl_{next(_counter)}"
    gmsh.model.add(name); gmsh.model.setCurrent(name)
    try:
        gmsh.merge(str(path)); gmsh.model.occ.synchronize()
        yield gmsh
    finally:
        gmsh.model.setCurrent(name); gmsh.model.remove()   # 一次性 model 用完即弃
```

**为什么不是 initialize/finalize 一对**：`.geo` 的 `Macro` 定义是**进程级永久状态**——`finalize`、`gmsh.clear()`、
`gmsh.parser.clear()` 都清不掉它，却会清掉 include-guard 变量（`qlib.geo` 的 `_QLIB_INCLUDED`）→ 同一宏库第二次解析必炸
"Redefinition of function"。唯一稳健口径：整个进程共用一个 session、每次解析进独立命名的新 model、用完 `remove`。
**代价**：`gmsh.option` 是全局的，每个调用点必须显式设全自己依赖的选项（尤其 `Mesh.Algorithm3D`：HXT 回退会改它，下次要复位）。

**拆解**：
- **为什么完整求逆取 θθ 块**：共模电荷守恒 = 0 的正确约化只在完整逆里体现；"删共模行列再求逆" = A⁻¹，只在 B = 0 时等价。
  闭式检查点：对地 50/40 fF、岛间 30 fF → C_eff = 30 + 50·40/90 = 52.222 fF；把 b 静默接地会得 67.14 fF。
- **数据**（two_pads，10 nH）：C_Σ = 24.378 fF（Maxwell 对角 24.532，对地 22.585——都不是它），E_C = 0.7946 GHz，
  f01 = 9.3989 GHz，α = −794.6 MHz，EJ/EC = 20.57，β = 0.0794，g = 373.0 MHz。
- `_invert_matrix`（`:154-183`）是手写 Gauss-Jordan（矩阵 ≤ 10×10，不引 numpy）；奇异判据**尺度相对**：pivot ≤ 1e-12·max|C|。

### 7.3 χ 与谐振器（`circuit_model.py:97-147`）


## 13. 预期问答

**Q1 为什么用零厚度片，真实金属明明有厚度？**
静电里导体内部无场无自由度，它的身份是边界条件。真实膜厚 100–200 nm 对 C 的几何因子影响 ≈ 1–1.8%；v3 的 2 µm 人工板
反而带 ~7.6% 量级的偏置。业界（Palace 官方例、KQCircuits、SQDMetal、Q3D）默认都是零厚度 PEC。

**Q2 为什么 order 2 是"承重件"？**
同网格 order 1 偏 +7.3%（two_pads 实测），sung 上 +5.4～5.8%——正是这个正偏让 v3 的 Elmer 档"碰巧"对上论文。
电容收敛对 p 加密远比 h 加密敏感。

**Q3 C_Σ 为什么不是 Maxwell 对角？**
Maxwell 对角 = 该导体对"其余全部接地"的电容；transmon 看到的是其它岛**浮动**时的 dressed 电容 = 1/[C⁻¹]_ii。
two_pads：对角 24.53、对地 22.59、C_Σ 24.38 fF，三个都不同。

**Q4 g 为什么用 f01 而不是裸等离子频率 f_p？**
文献真实分叉：Blais RMP / 旧 qiskit LOM 用 f_p，Krantz Eq. 105 与本实现用 f01 = f_p − E_C/h。EJ/EC = 20 时差 7.9%。
契约钉死了一支；跨文献比 g 先对口径。

**Q5 分块什么时候不能用？**
两导体只在同一次求解中共现才有直接互容；跨块直接互容 = 结构性零。相消型 coupler 的零耦合点直接依赖 q–q 直接腿——切错块
会移动甚至消灭零点。纪律：有意直接耦合的导体对同块共现。`build()` 对几何邻近却从不共现的对告警。

**Q6 为什么必须 `HWLOC_COMPONENTS=-gl`？**
WSL2 上 hwloc 的 gl 插件用 TCP 探测 X display，把 `MPI_Init` 挂死。`build()` 自动注入；裸机不需要。

**Q7 gmsh session 为什么永不 finalize？**
`.geo` 的 Macro 是进程级永久状态，finalize 清不掉它却会清掉 include guard → 同一宏库二次解析炸 "Redefinition of function"。
共享 session + 一次性 model 是唯一稳健口径。

**Q8 sung 为什么只能到 ±8%，而 v3 的 Elmer 到 ±3%？**
Elmer 档是 P1 正偏与简化版图缺失（无 junction leads / 读出爪 / 控制线，−4～6%）相互抵消。同网格 order 1 我们对 Elmer <1%
（管线正确性外证），order 2 才是物理更收敛的值。锚不动，容差按物理账改。而且版图对称 ⇒ QB1 = QB2，论文的 99.3 / 101.9
不可能同时命中。

**Q9 结果能信到几位？**
契约测试钉的是自洽性（rel 1e-9）；物理精度另算：网格两档跨 0.8%（two_pads）到 5.5%（sung，未收敛），LOM 微扰式在
EJ/EC ≈ 20 时几个百分点。业界即使三求解器互差 <0.3%，对**实验**频率 RMSE 仍 ~6%、g ~24%。

**Q10 哪些没做？**
`targets:` 声明期望值（#23）、收敛扫描/不确定度（#26）、第二求解器后端（#25）、AMR、CI、CLI。分块结果的拼装 `build()` 不自动做。
