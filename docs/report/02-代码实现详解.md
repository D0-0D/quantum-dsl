## 0. 心智模型（先记住这 6 句）

1. **一个 gmsh 模型是汇合点**：模板实例、手写 `.geo`、路由全部按顺序写进同一个模型；下游只读它的 2D Physical 组（`geo_model(source)` 接受可调用的 `Layout`），GDS / 网格 / Palace 一行未改。
2. **模板 = 局部坐标 `.geo`（不打名）+ 同名 yaml 接口**。编排器每步：参数与端口变量 → 解析器变量（未注入的引用名先置 NaN）→ merge → 新面差集 → 仿射变换 → 读输出变量 → 按实例名挂名。
3. **component 段 = net**。多岛 `<实例>_<岛键>`；连接型路由体的 component **就是** net 名，在结记账之前定下（`_net`）。
4. **路由是电连接**：两端外挂面（爪、桨）改挂 net；路由体必须真碰到每一端；每个端口只连一次。三条路（连接型模板 / 手写 `connect:` / `planner: cpw`）共用 `_connect`。
5. **手写只增不改**：每个 `geo:` 步骤前后快照已有面（tag / 面积 / bbox），有变化即 raise；merge 的文件里不许定义 `Macro`（宏走 `Include`）。
6. **纪律一律 raise**：未连接外挂面、未认领面、跨 net 同层相接（`getDistance ≤ 1e-6`）、全名重复、层 kind 不符、`if:` 指向未声明参数、输出变量 NaN。

## 1. 模板加载与校验（`_load_template`，`layout.py:166`）

- 搜索 `templates:` 目录：`<dir>/<name>.yaml` 或 `<dir>/<name>/<name>.yaml`，同名 `.geo` 可选（无 `.geo` 的模板只有 `steps:` 嵌套）。
- 顶层键白名单 `_TEMPLATE_KEYS`（`layout.py:48`）；各段子字典键白名单 `_ENTRY_KEYS`（`layout.py:55`）——`iff:` 这种拼错曾静默丢掉守卫。
- `kind:` 只许 `connect`；`planner:` 只许 `cpw` 且必须 `kind: connect`、必须声明参数 `R / n_legs / gap / lead`（`_PLANNER_PARAMS`，`layout.py:52`）。
- `_included`（225）递归走 `.geo` 里的 `Include`，把宏库也记进 `Layout.inputs` → manifest 哈希覆盖宏库（改 `cpw_macros.geo` 会变哈希）。

## 2. 步骤执行：位姿、参数、认领（`_template_step`，`layout.py:450`）

### 2.1 位姿 = 2D 仿射 `(a, b, c, d, tx, ty)`
`_pose(at, rot_deg, mirror)`（112）：镜像 → 旋转 → 平移；`_compose(outer, inner)`（125）嵌套复合；`_apply` / `_apply_angle`（132 / 137）变换点与角。
连接型的位姿由两口算出（§3），`planner:` 模板位姿恒等。

### 2.2 参数与注入（`_run_geo`，`layout.py:613`）
```python
poison = set()                                   # 模板 yaml 引用到的全部输出变量名
for section in ("islands", "external", "etch", "junction", "outputs"):

poison.update(_port_refs(doc.get("ports")))      # port(i) 简写先展开成 port_x/y/a/w 再置毒

    self.P.setNumber(k, [float(x) for x in v] if isinstance(v, (list, tuple)) else [float(v)])
new, pnew = self._merge(tpl.geo, where)          # 差集 = 新面
```

参数必须是有限数（`bool` 也拒）；连接型不许自己声明 `D / w / L`（编排器注入）。

### 2.3 认领与结
- 岛：`comps[key] = full if 单岛 else f"{full}_{key}"`；连接型 `comps[body] = net`（`layout.py:520-528`）。
- 外挂面：component 先留 `None`、记 `ext=(实例, 键)`，等路由来认领；`if:` 守卫未声明的参数 → raise（`enabled`，536）。
- 结（`_junction`，634）：编排器按模板给的两端点 + 宽画矩形，挂 `jj::<层>::<实例>::jj`；步骤必须给 `E_J / L_J / squid` 恰一个，生成 `circuit_model.qubits` 条目（`island` 或 `islands: [a, b]`）。
- 端口：`Port(x, y, a, w, layer, leq, net, ext)`；`port(i)` 简写展开为 `port_x(i)…`；变换后按 `实例.端口` 入表，同时注入 `<实例>_<端口>_x/y/a/w` 供后续手写步骤读。

## 3. 连接

### 3.1 位姿与正对检查（`_connect_pose`，`layout.py:708`）
```python
p, q = self._port(step["from"]), self._port(step["to"])
D = hypot(q.x - p.x, q.y - p.y)                      # 两口距离 → 注入 D
if abs(p.w - q.w) > _TOL: raise  (taper 未实现)
if p.layer != q.layer: raise
if planner:                                          # 规划器自己找路: 位姿恒等, 不要求正对, mirror 无意义
    if mirror not in (None, False): raise
    return ends, _ID, D, p.w
axis = atan2(q.y - p.y, q.x - p.x)
if not (_angles_equal(p.a, axis) and _angles_equal(q.a, axis + pi)):
    raise "… ports must face each other … — use cpw_route (planner: cpw) or hand-write the .geo"
if mirror not in (None, False, "x"): raise           # mirror: y 会翻转 from→to 轴本身

```

### 3.2 net 规则（`_net`，797）与电连接（`_connect`，808）
```python
island_ends = [(ref, p) for ref, p in ends if p.net is not None]
if len(island_ends) == 2: raise   # 两块命名岛的电气合并没有唯一名
```

```python
def touches(tags): return any(self.occ.getDistance(2, u, 2, v)[0] <= _TOL for u in body for v in tags)
for ref, _ in ends:                        # 端口只能连一次 (同一表里重复也算)
    if ref in self.used: raise
for ref, p in ends:

        if not touches(far): raise "gap between body and port?"
        continue
    hit = [t for t, f in self.faces.items() if f.ext == p.ext]
    if not hit: raise                      # 外挂端口背后没画面 (if: 守卫不一致)
```

`body` = 本步骤画的 net 金属面；手写 `connect:` 与连接型模板传的是各自那一步的面表。

### 3.3 定长（`_length`，761）
`{mode: fixed, L}` 或 `{mode: quarter_wave|half_wave, f_r, film_nm}` → `guided_wavelength`（中心导体宽 = 端口宽，缝 = 模板参数 `gap`，衬底取 meta）→

## 4. 自动布线（`route.py` + `layout.py:_plan` + `lib/cpw_route.geo`）

### 4.1 规划器（纯 math，`import quantum_dsl` 不拉 gmsh；v2，`route.py` 993 行）
- 流程 = **引出 → 骨架 → 填充 → 自检**。位姿 = `(x, y, heading)`，start 的 heading = from 口外法向，end 的 heading = to 口外法向 + π（驶入）；两端先沿位姿直走 `lead`。
- 骨架：默认曼哈顿框架 `axis`（deg，0 = 横平竖直）——`_end_arcs` 把两端位姿各转到框架四个方向（≤ 5 位姿 / 端，恰 180° 两侧都算），`_connectors` 在 h₁ = +x 的框架里出直 / Z / U / L / 三折候选（自由参数 = 居中 / 贴紧规则值 + region 格子中心的投影，让中段能挑走廊），`_fillet_path` 做 90° 圆角；`axis="free"` 走 v1 的 `_dubins_csc` 四型。全部候选按 **（转弯数, 长度）** 排序（曼哈顿路径多拐一次反而短 0.43R），出区域或**自身两段太近**（`_self_clear`：沿路间隔 ≥ πR 的原语中心线 < 2R）的丢弃，同（转弯数, 长度）一组由填充定胜负（块少 → 腿少 → 余量大）。
- 区域 `_Region`：矩形并集 = 外框（凸，`_samples` 取样点 + 内缩总宽/2，精确极值）− 缝（外框内不属于任何矩形的格子；`_dist_prim_rect` 用直段–线段 / 弧–线段的闭式距离查 ≥ 总宽/2）。
- 填充 `_fill_runs`：每条非引出直段一个 `_Run` 工作台（几何、障碍 `_obstacles` = 本条路其它直段**与弧**除去共端点的 + 已放好的块、按位置缓存的余量）。余量 `_Run._room` **精确**：半圆取样点沿 σn 的射线（外框 `_ray_exit_rect`、缝的两条 slab、直段胶囊 `_ray_capsule`、弧 `_ray_arc`）+ 界的角点 / 端点沿 −σn 射进加厚半圆（`_ray_arc`，= 圆盘碰半圆曲线）+ 两弧外切根。摆放网格 R/2（加居中与贴末端），所有腿数共用。`_fill` 取最少腿 + 最大余量；`u_k = R + λ(room_k − R)`。单段都装不下 → `_fill_subset` 按容量比例分摊到 2, 3, … 段（`_capacity` 算各段最大 E_max；容量小的先放，先放的块进后面块的障碍集；最大的一段吃精确余数；显式 `n_legs` 按容量分成各段 ≥ 2）。`_meander_parts` 按逐弯 u_k 生成块。每个成品候选过 `_self_clear`。
- `auto_radius`：整数区间 [⌈width⌉, min(外框短边, 两口距离)/2] 上二分，每步一次 `_plan_impl(with_hint=False)`；`plan_cpw(R="auto")` 用它；给定 R 失败时用同一搜索（R_max = R − 1）给出「R <= N um would fit」提示。
- 自检：输出前整条路重跑区域检查、净距检查、记账比对（≤ 1e-6），不过 → `internal:` raise；全部候选失败 → 一条 raise 逐骨架列原因（最多 8 条）与建议。
- 原语只有两种：`("line", x1, y1, x2, y2)`、`("arc", cx, cy, R, a0, a1)`（每段 |Δa| ≤ π/2，长弧拆段）。`path_length` 与 `.geo` 的 `cpw_length` 同口径。

## 5. 手写步骤（`_geo_step`，`layout.py:843`）

- `frame: <实例>`：在该实例位姿下 merge（可读 `<实例>_*` 端口变量）。`ports: {F0: {port: f0(0), net: F0}}` 声明端口（手写端口名扁平唯一，`net` 必须是本步挂名的 component）。
- `etch: 面表` + `layers: <芯片层>`（多层时必填，过 `_chip_layer` 校验）。
- `connect: {net: [端口…]}`：把外挂面归入手写挂名的 net，走 §3.2 同一条 `_connect`。
- 增量原则：merge 前后快照已有面的 `(tag, 面积, bbox)`，有变化 raise。`_merge`（351）在解析前扫文件，顶格 `Macro` / `Function` → raise
  （merge 的文件解析完即关闭，宏体随之失效；同进程第二次跑版图会 "Input in flex scanner failed" / 段错误；`Include` 的文件 gmsh 不关，这是宏库能活的原因）。

## 6. 地与收尾

- `_ground`（948）：`ground: sheet: {layer, margin_um}` 取该层 metal 面 bbox 外扩建矩形，一次 `cut` 掉全部蚀刻工具面，挂 `ground::<层>::GND::sheet`；`none` 丢弃工具面（flip-chip）。
- `_finish`（988）：未连接的外挂面 raise；每块面须被岛 / 外挂 / 蚀刻 / 结 / 手写名之一认领；不同 net 同层导体 `getDistance ≤ 1e-6` → 短路 raise（同 net 放行）；全名唯一；最后按 component 分组 `addPhysicalGroup`。
  分块（`for_block`，307）：只给块内 component 挂名，其余面在 `build_mesh` 里当孤儿删掉。手写 Physical 组先 `removePhysicalGroups()` + 逐名 `removePhysicalName`，再按 keep 重挂——逐组删会留残名、出网格时 heap 崩。

## 8. 上云与后处理（脚本形态，不在产品代码里）

云机（阿里无影 c24a1，64 核 / 128 G）只有 spack Palace 0.16，无 gmsh。流程：本机 `build(m, out, solve=False)` 出 `*.msh` + `*.json`（要改 d 或网格档就 `dataclasses.replace(meta, airbox=…, mesh=…)` 后 `build_mesh` + `palace_config`）→ `rr -p` 推 → 远端
`OMPI_ALLOW_RUN_AS_ROOT=1 palace -np N cfg.json`（`run_palace2.sh` 顺带每 5 s 采样该任务 palace 进程 RSS 之和）→ `rr -f` 拉回 `postpro/` →
`parse_capacitance(postpro, labels=sorted(metal components))` + `solve_circuit_model(labels, maxwell_fF, junctions)`（结取 `Layout.qubits`，E_J 乘 h）。
labels 顺序 = `sorted(component)`，与 `Terminal.Index` 对齐，是全链唯一真相源——后处理不需要网格文件。

## 9. 预期问答

- **为什么不用 Python 直接调 gmsh API 画模板？** 用户要的库要与「正常写 `.geo`」同一种语言；API 模板只留 `py:` 逃生口（未做）。两者对编排器同构：都产生新面 + 输出变量。
- **为什么不 fork gmsh 给宏加参数？** bison 直译无 AST，宏是 `fgetpos/fsetpos` 跳转，3–4 人周只能做语句级；官方 wheel 是自编静态 OCCT 打包，fork = 永久私有构建链。编排器在 Python 侧注入参数已解决问题。
- **模板 `.geo` 里 Physical 名怎么办？** 模板不打名（打了 raise），编排器按实例名挂；手写步骤可以自己打名（`metal::ta::RP00::pad`），只增不改。
- **`planner: cpw` 的路为什么在芯片坐标里规划？** `region:` 是芯片坐标的矩形（或并集），不用变换；`mirror:` 对它无意义 → raise。正对共线且无 region 时曼哈顿骨架退化为一条直段、蛇形等腿居中，闭式与宏相同，所以与 `cpw_meander` 逐段相等（测试锚）。
- **自动腿数为什么取最小 n？** 振幅随 n 单调减，最小 n = 最大振幅可行解，先「装得下」；要紧凑改取最大 n 是一行事，待拍板。
- **两口都是岛（pad↔pad）能连吗？** `_net` 两岛端 raise：两块命名岛的电气合并没有唯一名。要馈线得先定命名规则。
- **块解为什么会「删爪」？** `for_block` 只给块内 component 挂名，其余面在 `build_mesh` 当孤儿删；块内比特伸向块外耦合器的爪属于块外耦合器的 net。十字实测这个偏差只有 −2.5% E_C。
- **块两两共享比特几何，能 `assemble()` 叠加吗？** 不能，会重复计入比特对地电容；`_warn_overlapping_blocks` 会告警。要整片就整片解（3×3 在 128 G 机装得下）。
- **Palace 内存怎么估？** 8.1–8.6 GB / 百万未知量（order 2，np 24–32）；末尾自报的 "Estimated peak per-node memory usage" 可信。杠杆在 `mesh.min_size_um`（4 → 6 内存 ÷2.7），求解器旋钮只有 5–8%。
- **YAML 布尔坑**：模板参数别叫 `on` / `off`（YAML 1.1 读成 True / False）。
