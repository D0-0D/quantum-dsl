### Demo E —— 纯数学：三行命令（对应汇报 §4.4–4.5）

**台词**：「物理内核不依赖 gmsh/Palace，可以直接喂数。」

```bash
# (1) 逆电容 LOM: 喂 golden 矩阵 + 10 nH
python -c "
from quantum_dsl import solve_circuit_model
r = solve_circuit_model(labels=('A','B'), maxwell_fF=[[24.5324,-1.9472],[-1.9472,24.5353]],
    junctions=[{'name':'A','islands':['A'],'L_J':10e-9},{'name':'B','islands':['B'],'L_J':10e-9}])
for q in r.qubits: print(q)
for c in r.couplings: print(c)"
# 预期: QubitResult(name='A', ..., C_sigma_fF=24.3779, E_C_GHz=0.79458, f01_GHz=9.39889, anharmonicity_MHz=-794.58, EJ_over_EC=20.572)
#       CouplingResult(qubit_a='A', qubit_b='B', beta=0.079368, g_MHz=372.975)

# (2) CPW: 5 GHz, 10/6 µm, 760 µm 硅, 200 nm 膜 —— 注意接口是 SI 米
python -c "
from quantum_dsl import lumped_cpw
r = lumped_cpw(freq=5e9, line_width=10e-6, line_gap=6e-6, substrate_thickness=760e-6, film_thickness=200e-9)
print(f'Z0={r.Z0:.3f} ohm  eps_eff={r.eps_eff:.4f}  lambda_g={r.lambda_g*1e3:.3f} mm  Lk/Lext={r.Lk/r.Lext:.4f}')"
# 预期: Z0=51.045 ohm  eps_eff=6.2248  lambda_g=23.965 mm  Lk/Lext=0.0056

# (3) 非对称 SQUID 磁通调谐: φ=0.5 有限 (无奇点式), 不是 nan
python -c "
from quantum_dsl import solve_circuit_model, H_PLANCK
for flux in (0, 0.25, 0.5):
    r = solve_circuit_model(labels=('Q',), maxwell_fF=[[100.0]], junctions=[{'name':'Q','islands':['Q'],'squid':{'E_J1':12e9*H_PLANCK,'E_J2':8e9*H_PLANCK,'flux':flux}}])
    q = r.qubits[0]; print(f'flux={flux:<5} E_J={q.E_J_GHz:6.3f} GHz  f01={q.f01_GHz:.3f} GHz')"
# 预期: flux=0     E_J=20.000 GHz  f01=5.373 GHz
#       flux=0.25  E_J=14.422 GHz  f01=4.534 GHz
#       flux=0.5   E_J= 4.000 GHz  f01=2.296 GHz

# (4) 拼装 + Schur: 两块共享节点 s, 消掉 s
python -c "
from quantum_dsl import assemble
out = assemble(cells=[{'name':'b1','labels':('a','s'),'maxwell_fF':[[5,-1],[-1,4]]},{'name':'b2','labels':('s','b'),'maxwell_fF':[[3,-2],[-2,6]]}], keep=('a','b'))
print(out.labels, [[round(v,4) for v in r] for r in out.maxwell_fF], out.eliminated)"
# 预期: ('a', 'b') [[4.8571, -0.2857], [-0.2857, 5.4286]] ('s',)
```

**指向**（4）：a、b 原本没有直接互容（−0），经 s 中介后出现 −0.2857——这就是"共享节点提供中介路径"。

## 4. 故障预案

| 症状 | 原因 | 处置 |
|---|---|---|
| Palace 启动后无输出、卡死 | WSL 上 hwloc gl 插件探测 X display 挂死 `MPI_Init` | `export HWLOC_COMPONENTS=-gl`（`build()` 自动注入；手动跑 Palace 要自己带） |
| `build(solve=True): Palace binary not found — set PALACE_BIN` | env 未激活或变量丢失 | `conda activate qdsl313` 或手动 `export PALACE_BIN=…/palace` |
| `build_mesh: empty 3D mesh … Delaunay and HXT both failed` | 几何退化 / 网格尺寸与几何量级不匹配 | 检查 `.geo` 是否有零面积面；调 `mesh.min_size_um` |
| `palace failed rc=…` + `signal 9` 无诊断 | OOM（sung 级网格峰值 154 G） | 换更大内存机；先用粗网格 sanity |
| `palace_config: outer_boundary 'open' with no ground:: surfaces` | 全悬浮问题奇异 | 加 `ground::` 面，或去掉 `outer_boundary: open` 用接地盒 |
| `label(s) […] are not claimed by any junction` | meta 的 `circuit_model` 漏了某个 component | 补 `island(s)`；或用 `assemble(keep=…)` Schur 消掉 |
| `Redefinition of function` | 在同一进程里绕过 `_gmsh.geo_model` 直接 `gmsh.initialize/finalize` | 只通过 `load_geo` / `build_*` 进 gmsh |
| gmsh GUI 不弹窗（WSLg） | wayland 插件缺失 | `export QT_QPA_PLATFORM=xcb` |
| live 测试 skip | 闸门未开 | `QDSL_RUN_PALACE=1`（two_pads）/ `QDSL_RUN_PALACE_SUNG=1`（sung） |
