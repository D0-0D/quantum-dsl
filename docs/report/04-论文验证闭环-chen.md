# 论文外部验证的完整账：Chen et al. 2025（Nat. Phys. 21, 1489）圆盘比特阵列

> 对象：Z. Chen, W. Liu, … J. Chen, F. Yan（BAQIS / 清华），*Efficient implementation of arbitrary two-qubit gates using unified control*，
> Nature Physics **21**, 1489–1496 (2025)，doi 10.1038/s41567-025-02990-x，arXiv:2502.03612，补充材料（SI）§A–§R。
> 本文回答一个问题：**我们从照片量出的几何 + 静电 FEM，对论文给出的参考值预测到什么程度，偏差在哪一层，为什么。**
> 数字全部来自 2026-09-13（本机 QCQ 块）与 2026-09-18（阿里云 c24a1，64 核 / 128 G，Palace 0.16，order 2）实测，
> 产物 [`../../.claude/chen-evidence/`](../../.claude/chen-evidence/README.md)，过程账 `.claude/session/2609131337.md` / `2609180210.md`。
> 几何取证与量法在 [`../design/paper-chen2025-geometry.md`](../design/paper-chen2025-geometry.md)，物理口径在 [`../physics.md`](../physics.md) §13。

## 0. 先看结论

1. **实测非谐 α 命中。** 论文 Table SI 给 12 只比特实测 α = −179～−200 MHz（均值 **−192 ± 6**）。十字几何（中心比特带全部四只爪）
   整片一次解，flip-chip 间隙 **d = 4.0 µm 时中心比特 α = −190.7 MHz**，落在均值 ±1σ 内；f01 = 4.16 GHz（实测 f_max 4.03–4.25）。
   d 是唯一旋钮：d = 4 / 5 / 7 → E_C 190.7 / 214.5 / 250.4 MHz，∝ d^0.49。网格两档只移 0.3%。
2. **但 d 的两个外部锚拉向相反方向。** 同工艺（BAQIS flipmon）实测 d = 5 ± 0.4 µm；论文 SI 自己的电容表推出 E_C = 209，对应 d ≈ 5.2。
   即在相同 d 下我们的几何比 SI 的电磁模型少约 10% 的 C_Σ；而 SI 的模型与实测（192）本身也差 9%。**命中实测靠的是 d 吸收了这 10%。**
3. **互容缺口与 d 无关，是几何。** 半盘–半盘 / 半盘–条 / 条–板互容恒为 SI 值的 0.35–0.5 倍，对 d（4→7 只动 +6～14%）与周边环境都不敏感。
   它们由 10–15 µm 级间隙决定，而这些量在照片上只有 ±30–50%。g_qc（55–67 vs 设计 90）、g_qq（2.6–3.7 vs 设计 5）偏低全部由此而来。
4. **环境效应小，块解够用。** 中心比特（四爪）比单爪臂比特只低 2.5% E_C；3×3 整片解的中心比特与十字到 0.1 MHz 相同；
   每多一只爪 E_C −1.8 MHz。此前 QCQ 块解"删爪偏差"只落在多爪比特上、只值 2.5%。
5. **SI §G 实测的 ~2 MHz 次近邻残余耦合不是静电直接项**：3×3 里对角比特的直接 g 只有 0.03–0.05 MHz（半盘–半盘互容 7×10⁻⁴ fF）。
6. **SI 关于电磁仿真只有一句话**（"We numerically calculate the QCQ system capacitance from electromagnetic simulations"），
   不写工具、不写 d、不写边界、不写包含哪些金属——「我们的口径 vs SI 的口径」无法从文本闭合，只能用多画 / 少画两档自证。

## 1. 论文给了什么（三层真值）

### 1.1 实测（Table SI，12 只比特；α 是本次唯一「多样本实测 + 我们能无调参预测」的量）

| | Q0 | Q1 | Q2 | Q3 | Q4 | Q5 | Q6 | Q7 | Q8 | Q9 | Q11 | Q12 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| f_max (GHz) | 4.112 | 4.175 | 4.145 | 4.243 | 4.115 | 4.094 | 4.102 | 4.146 | 4.171 | 4.247 | 4.029 | 4.092 |
| **α (MHz)** | −179.1 | −192.0 | −200.4 | −194.5 | −195.4 | −187.9 | −192.1 | −194.7 | −186.4 | −200.2 | −194.1 | −192.3 |
| f_read (GHz) | 7.112 | 6.866 | 7.035 | 6.767 | 7.148 | 6.891 | 7.063 | 6.893 | 7.135 | 6.736 | 7.068 | 6.816 |

α 均值 −192.1，标准差 6.2（3.2%）。SI **不给**比特编号与晶格位置的对应，也不说哪只是边缘比特；器件是 72 比特方格阵列，
用到的 12 只几乎肯定都是四配位内部比特（推断）。另有 SI §G：次近邻（对角）比特残余耦合"typically ∼2 MHz"（Fig. S6）。

### 1.2 设计值（SI §D 末）

ω_q/2π = 4.1 GHz，α_q/2π = **−185 MHz**，g_qc/2π = **90 MHz**，g_qq/2π（直接）= **5 MHz**，ω_c/2π ≈ 5.2 GHz（有效耦合为零处）。

### 1.3 SI §D 电容表（孤立 QCQ，6 块金属板 + 地，电磁仿真值，fF）

节点 1, 2 = Q0 两半盘（2 靠条）；3 = 条；4 = 五边形；5, 6 = Q1 两半盘（6 靠条）。

| 对地 | | 互容 | |
|---|---|---|---|
| C01 / C02 | 137 / 119 | C12（Q0 两半盘） | 23 |
| C03（条） / C04（五边形） | 133 / 165 | C34（条–板） | 28 |
| C05 / C06 | 137 / 119 | C23（半盘 2–条）/ C36（条–半盘 6） | 26 / 26 |
| | | C56 | 23 |

图上没有 Q0–Q1 直接互容、没有五边形对半盘的互容——即 SI 的口径就是"孤立 QCQ，六块板"。
**SI 网络自身闭合**（用 SI 自己的 Σ/Δ 变换 + 逆电容公式）：E_C(q) = **209 MHz**，E_C(c) = 171，g_qc = 71，g_qq = 9.1——
对 SI 自报的设计值 −185 / 90 / 5 分别差 +13% / −21% / +80%。**论文自己的两套数字之间就有 10–20% 的缝**，这是任何容差讨论的地板。

### 1.4 SI 关于仿真口径的全部原文

> "The qubit-coupler-qubit(QCQ) system base on capacitive coupling is shown in Fig. S4 with both the qubits and coupler floating.
> We numerically calculate the QCQ system capacitance from electromagnetic simulations: C01 = 137 fF, …"

全 SI 检索 HFSS / COMSOL / Q3D / finite element / ground plane / boundary：零命中。§E 只说 In bump "approximately 10 µm in height"（压合前）。
Maxwell 约定那句还有笔误（"M11 = C01 + C13"，C13 不在表里，括号未闭合）。

## 2. 几何从哪里来

- **全部尺寸只能从 Fig. 1a 照片量**（正文 / SI / arXiv 无任何 µm 数字），比例 2.50 µm/px（0.5 mm 标尺 = 200 px，±0.5%）。
  大结构可信 1–3%：盘径 390、晶格 1383、条宽 30、五边形 378 × 300、爪厚 40 / ±20°；**10–15 µm 级间隙只有 ±30–50%**：
  缝 70、盘–爪 12、条–板 75、颈 20。量法与逐项置信度见几何稿 §3。
- 采用值写在模板参数里（`examples/lib/disc_transmon.yaml` / `bar_coupler.yaml`），≤15 µm 的量默认值标"照片估计"。
- 结：E_J 由 SI 设计值反推（ω_q 4.1 GHz + α −185 → 12.4 GHz；ω_c 5.2 + E_C(c) 171 → 21.1 GHz）。器件是 SQUID，静电不看磁通。
- **不画**：读出爪（225°）、45° 方焊盘、λ/4 谐振器、载片走线、空气桥。

## 3. 模型口径

- **flip-chip**：比特与耦合器在顶片（Ta / 蓝宝石），**顶片无地平面**，地是隔真空间隙 d 的载片。管线里 `ground: none` +
  `airbox.top_um = d` + `solver.outer_boundary: ground`（盒顶 z = +d 接地）就是它，不需要新词汇。盒侧壁 / 底面（≥300 µm 外）同样接地，是次级项。
- 蓝宝石标量 ε = 10（各向异性 9.4 / 11.5 未做），430 µm；地在金属另一侧隔 5 µm 真空，衬底是次级项。
- 网格 100/4（`max_size_um` / `min_size_um`），order 2；报数前做了 80/3 第二档。
- 三种几何，各对什么：

| 几何 | 导体 | 对什么 | 未知量 / 内存 / 用时 |
|---|---|---|---|
| QCQ 块 H01（3×3 的 `extract.blocks`） | 6 | SI §D 六块板口径；块外一切面（含块内比特伸向块外的爪）当孤儿删掉 | 105 万 / 10 GB / 本机 8 rank 573 s，c24a1 np=32 93 s |
| **十字**（`chen_2025_cross`） | 18 | 中心 Q11 四爪 = 真晶格口径 ↔ 实测 α；四臂比特各一爪 = SI 孤立 QCQ 的比特侧；同一张网格作差 = 环境效应 | 334 万 / 28.6 GB / np=24 19 min |
| 3×3 整片（`chen_2025_3x3`，不分块） | 42 | 配位数 2 / 3 / 4 的比特同框；阵列级耦合（最近邻、对角、耦合器–耦合器） | 812 万 / 69 GB / np=32 86 min |

## 4. 数字怎么算出来的

1. Palace 静电 → Maxwell 矩阵 M（`terminal-C.csv`，SI 法拉 → fF）。对地 = 行和；互容 = −M_ij。
2. `solve_circuit_model`：每个浮动结 `islands: [a, b]` 做 Σ/Δ 变换，完整求逆取 θθ 块 → C_Σ = 1/[C′⁻¹]_θθ，E_C = e²/2C_Σ，
   α = −E_C/h，f01 = (√(8E_C E_J) − E_C)/h，g = ½β√(f01_i f01_j)。与 SI 的 S16 / S24 公式同口径（我们复算 SI 表得 209 / 171 / 71 / 9.1，与 §1.3 一致）。
3. 结条目由编排器从模板 `junction:` 自动生成（十字 9 条、3×3 21 条），E_J 取 §2 的反推值。
4. 上云：本机 `build(..., solve=False)` 出 msh + json → `rr -p` 推到 c24a1 → `palace -np N cfg` → 拉回 `postpro/` → 本机后处理。
   Palace 0.16 末尾自报的 "Estimated peak per-node memory usage" 与外部采样一致（28.6 vs 28.1–28.3 GB），可当预算依据。

## 7. 归因

1. **对地项 ↔ d**：近似 ∝ 1/d。对上 SI 电容表要 d ≈ 6–7，对上实测 α 要 d = 4。两个锚方向相反，因为 SI 的电磁模型与实测本身不闭合（209 vs 192）。
   我们在 d = 5 复现 SI 表闭合出的 E_C 到 +2.6%，是因为单项偏差（对地 ×1.1–1.45、互容 ×0.4–0.5）在 E_C 里大半抵消。
2. **互容 ↔ 间隙几何**：C12 由缝 70 定、C23 由盘–爪 12 与爪角跨定、C34 由条–板 75 定；这三个量在照片上是 C 级（±30–50%）。
   互容对 d 的响应只有 +6～14%（d 4→7），对环境零响应——它们不可能由 d 或周边结构补回。g_qc / g_qq 偏低是这条的直接后果。
3. **环境**：四爪 vs 单爪只差 2.5% E_C——多出的爪主要把半盘的场从"对地"改道成"对耦合器互容"（d = 5 时中心半盘对地 133 vs 臂 145 / 153），C_Σ 净增 2.2 fF。
4. **未画读出结构**：读出爪（8 760 µm²，贴盘 6–12 µm，静电上接地）估给 SW 半盘 +10～15 fF 对地 → C_Σ +3%，α −3%；焊盘 260 µm 外在 5 µm 地平面下被屏蔽，<0.5 fF。
   方向已知且单向：补上它，标定的 d 会从 4.0 走到约 4.3。
5. **数值**：网格两档 0.3%，Elmer 交叉在 v4.0 已证 1.9e-7，order 2 是承重件——数值不是本次任何一条偏差的来源。
6. **E_J**：论文不给每只比特的 E_J，f01 用设计 E_J 算，只能作量级检验。

## 8. 验证了什么、没验证什么、下一步

**验证了**：从照片几何 + 单个物理旋钮 d，能无调参地把四配位比特的 α 预测到实测均值 ±1σ（d = 4.0）；模型对 d、网格、环境的响应量化清楚；
SI 网络拓扑（哪些互容可忽略）与我们一致；十字对比特级量已足够，3×3 只在阵列级耦合上多给信息。

**没验证**：g_qc / g_qq（只有设计值，且互容缺口主导）；g(Φ_c) 门用耦合（静电无磁通轴）；读出频率 / χ（几何在分辨率以下）；次近邻 2 MHz（非静电项）。

**下一步**（按杠杆排序，均在 `.claude/plan.md`）：① gap ±3 µm 灵敏度（缝 70 / 盘–爪 12 / 条–板 75），看互容能否回到 SI 的一半以上；
② 读出爪进十字（+3% C_Σ，d 标定 → ~4.3）；③ 蓝宝石各向异性 ε 9.4 / 11.5；④ 在 d = 4 处把 SI 的 11 个电容作为预测报出。
