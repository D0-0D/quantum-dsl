真版图 `sung_2021_xmon`，零调参（C_Σ 单位 fF；论文拟合 E_C 换算值 99.3 / 227.9 / 101.9，β_qc = 0.0364）：

四句话：

1. **管线没错。** Palace order 1 与 ElmerFEM 在同一张网格上给出逐位相同的电容矩阵（10⁻⁷）；两版几何（逐点描摹 vs 参数化）
   契约级差 ≤2.4%。后面所有差异都不来自求解器、网格转换或几何翻译。
2. **一阶元偏高、电容从上方收敛。** 同网格换阶掉 15～17%，再加密网格掉 5%，方向一致、仍未收敛——真值在报出值以下。
   "order 1 粗网格接近论文（+9～11%）"是离散过估的巧合，不是准。
3. **不调参就不命中。** Xmon 落论文 **−12～13%**，coupler **−30%**，β_qc **+12～17%**。测量误差预算（§3）最坏解释 Xmon 那 12% 的一半，
   coupler 的 30% 解释不了——剩下的是几何：二维顶层照片里没有的结构（读出爪、空气桥、SQUID 环、封装环境），以及论文 Table VI 的
   C_c 本身是集总模型总电容。
4. **这才是预测精度的真实量级。** 业界对实验的频率 RMSE ~6%、g RMSE ~24%；本仓用不完整的顶层几何预测到 12～30%。替代几何
   `sung_2021_device` 的 ±3～6% 是标定命中（§8），与此不冲突。

真版图例子**不设判据**——它是预测，数字如实记录在两份 meta 头注。

## 1. 论文给了什么

Sung, Ding, Braumüller 等（MIT EQuS / Lincoln Lab），*Realization of High-Fidelity CZ and ZZ-Free iSWAP Gates with a Tunable Coupler*，
Phys. Rev. X 11, 021058 (2021)，arXiv:2011.01261。主题是两比特门（60 ns CZ 99.76%，30 ns ZZ-free iSWAP 99.87%），不是版图。

**器件**（正文 §II、Fig. 1、Appendix B）：QB1 — CPLR — QB2 一字排开。QB1 固定频率 4.16 GHz（单结）；QB2（3.7–4.7 GHz）与 CPLR
（3.7–6.7 GHz）用非对称 SQUID 磁通可调。Fig. 1(c) 照片显示两只比特是**十字形（Xmon）岛**、耦合器是一条**梳齿岛**，三者都与周围地平面
隔一圈缝、由结接地——**接地 transmon**。Table VI 用"C_1、C_c、C_2 对地 + C_1c、C_2c、C_12 互耦"的三节点接地网络描述它。
**论文正文与 arXiv 源码里没有任何版图尺寸**（只给了结面积 1–3 µm × 200 nm）；版图只存在于那张照片里。

**真值分三层，性质不同：**

| 来源 | 内容 | 性质 |
|---|---|---|
| Table I | ω/2π = 4.16 / 5.45 / 4.00 GHz（idle）；η/2π = −220 / −90 / −210 MHz；g_1c = 72.5、g_2c = 71.5、g_12 = 5.0 MHz（**脚注 c：在 ω_1 = ω_2 = ω_c = 4.16 GHz 处**） | **直接实测** |
| Fig. 7 图注 | 拟合电路参数：QB1 E_J/h = 12.2、E_C/h = 0.195 GHz；CPLR E_J1/h = 46、E_J2/h = 25、E_C/h = 0.085 GHz；QB2 E_J1/h = 13、E_J2/h = 2.8、E_C/h = 0.19 GHz | **对磁通谱拟合**（Koch 2007 模型） |
| Table VI | C_1 = 95、C_c = 228、C_2 = 98、C_1c = C_2c = 5.36、C_12 = 0.125 fF | **数值仿真的输入**，论文没说来自实测还是设计仿真 |

静电求解能对上的只有第二、三层。E_C = e²/(2C_Σ)，用 e²/(2h) = 19.370 fF·GHz：0.195 → 99.3 fF，0.085 → 227.9 fF，0.190 → 101.9 fF。
Table VI 自算的节点总电容是 100.5 / 238.7 / 103.5——与拟合值差 −1.1 / −4.5 / −1.5%，**论文自己的两套数字对耦合器就差 4.5%**，这是任何
容差讨论的地板。f01 = √(8E_C E_J) − E_C 反算 4.17 / 6.86 / 4.71 GHz，对上 QB1 实测与两只可调单元的调谐上沿，说明 E_J 取零磁通
最大值（71 / 15.8 GHz）的口径抄对了。β_qc = C_1c/√(C_1 C_c) = 0.0364（本仓的逆电容口径在同一网络上算得 0.0346，两种定义差 ~5%）。

## 2. 真版图怎么从照片量出来

### 2.1 源图与比例

arXiv e-print（`arxiv.org/e-print/2011.01261`）的 `fig1_device_layout.pdf` 内嵌的就是那张 **922×489 px 显微照片**（CMYK TIFF，
与 PRX 版同一张，没有更高分辨率版本）。图上的 **100 µm 标尺是矢量**：`"100 μm"` 文字正上方一条 15.83 pt 的线；图像放置
221.28 × 117.36 pt → x、y 均 4.1667 px/pt（各向同性）。100 µm = 65.96 px ⇒ **1.5161 µm/px**，视场 1398 × 741 µm，
每条边 ±1 px ≈ ±1.5 µm。

### 2.2 描摹版 `sung_2021_xmon_traced.geo`（`tools/micrograph_to_geo.py` 生成，不手改）

1. **二值化。** 灰度直方图双峰：Si 87–110、Al 220–255；阈值取范围中点 143.5。浅 = 金属，深 = 裸 Si。
2. **分类。** 金属 8-连通分量：触图像边界 → 地（被视场截断的控制 / 读出线，等价于在视场边缘接地）；内部 ≥500 px → 岛（恰 3 个，
   按 x 命名 QB1 / CPLR / QB2）；<500 px → 缝（空气桥焊盘、结碎片）。缝 4-连通分量 ≥30 px → 地洞（12 个：三个 moat + 9 条线槽）。
   **唯一手工擦除**：(357,114) 处 7×7 px，一条线的末端被阈值粘到梳齿顶（连通性测试定位：唯一能让梳齿与地分离的点）。
3. **轮廓 → 多边形。** 0.5 等值面轮廓（落在像素边界）→ Douglas–Peucker 1 px → 边分类（|dy| ≤ 0.35|dx| 水平、反之竖直、其余保留
   45° 斜边）→ 顶点 = 相邻规范线交点 → 半像素格取整 → 去共线 → 折叠 <1 px 短边。共 426 个顶点。
4. **坐标与结。** x = (px − 461)·1.5161，y = (244.5 − py)·1.5161，原点 = 照片中心，y 向上，单位 µm。三个结的引线低于分辩率，按 2 µm
   宽集总 `jj::` 条从岛端补到地（GDS layer 20，不进静电网格）。
5. **写成 `.geo`。** 每个多边形 = 一段注释（是什么、多大、在哪）+ 一张坐标表 + `Call POLY`（`qlib.geo` 新增的通用多边形宏）。

在最终多边形上量得（亚像素，shapely 直线求交）：Xmon 臂宽 30.3 / 30.3，臂端到地缝 32.2 / 30.7，臂端到端 338 / 341 µm；梳齿 24.3、
齿间缝 26.2、地指 20.5、底梁 25.8 µm；两 Xmon 中心距 703 µm。与灰度剖面的整像素游程（臂 20、缝 21、臂展 224、齿 16–17 / 缝 18 /
地指 13 px）一致。

### 2.3 参数化版 `sung_2021_xmon.geo`（发布的例子，72 行）

426 个顶点忠实但不可读、不可调。既然主导误差是 ±1 px 的边缘定位（§3），按理想形状压成参数不损失精度。每个数都是在描摹多边形上
**精确读出的**，没有一个是为凑论文设的：

- **Xmon**（`qlib.geo` 新增 `XMON` 宏 = 两条等长矩形臂的并；moat = 同形外扩缝宽）：QB1 中心 (−352.5, −44.5)，QB2 (350.2, −44.3)；
  臂宽 30.3；端到端 339 / 342；臂→地缝 32.2 / 30.7 µm。
- **梳齿 coupler**：底梁 x −273.7…272.1、y 34.9…60.6；6 齿宽 24.5、顶 185.0，齿位 −261.5 / −163.0 / −64.1 / 48.5 / 160.7 / 259.3；
  moat = 同组矩形外扩 26.5——齿间地指（≈21 µm，量得 20.5）与 qubit moat / coupler moat 之间那条 5 µm 地条都自然出现。
- **省掉**：视场内 5 条控制 / 读出线与贴着 Xmon 上臂的 L 形读出槽、空气桥、SQUID 框的 ∩ 带、描摹版 1 px 级不对称。

三个岛都接地，`circuit_model` 用单岛写法 `island: QB1`。两版 FEM 之差见 §7：C_Σ 1～4%，β_qc 0.4%。

**审计（图 B）**：多边形栅格与阈值掩膜差 7267 px = 视场 1.61%，其中 57 条是沿边 1 px 宽的条带或 45° 阶梯（边落在 ≤0.5 px 内的取整，

**误差预算：**

| F | 解释性干预（擦桥、空气桥、结引线并入岛、边界线接地） | 离散 | 局部 10 µm 级 | C_c ~1–2%，其它 <0.5% | 小 | 结构尺度估算 |

**合计**：最坏线性叠加 C_Σ(Xmon) ≈ ±6～9%，C_c ≈ ±8～10%，β ≈ ±11～16%；现实（RSS）C_Σ ±4～5%，C_c ±5～6%，β ±8～10%。主导项是
B（阈值），其次 A（比例，不可验证）。**参数化压缩的代价**（§7）：两版同网格同阶差 C_Σ 1～4%、β_qc 0.4%，与本预算同量级，所以参数化版
可以当例子。

对 D 做一次 FEM 敏感性。

两个实现坑（记在 `qlib.geo` / `_gmsh.py`）：gmsh 解析器变量进程级持久，生成器最初用累加数组 `foo_p() += p`，`build()` 第二遍解析残留

必须另起一行。

## 4. 数字怎么算出来的

`build(meta, out, solve=True)`，两版几何走完全相同的路：

1. `build_mesh` 把三个岛面与 ground 面作为零厚度片 imprint 进衬底 / 真空界面，导体边缘 Distance + Threshold 细化；契约配方 max 80 /
   min 2 µm（参数化版 12.8M 四面体，描摹版 15.4M），粗档 160/10（约 23～28 万）；Si ε_r = 11.45、厚 750 µm；airbox 顶 890 / 底 1650 /
   侧 200 µm；`outer_boundary: open`——盒壁不挂边界条件，电位参考由片上 `ground::1::chip::gnd` 提供；
2. `palace_config` 写 Palace 静电 config：`Model.L0 = 1e-6`（全仓唯一的 µm→m 换算点）、3 个 Terminal（顺序 = `mesh.labels` =
   `CPLR, QB1, QB2`）、`Ground` 只挂 ground sheet、`Solver.Order` 按 meta（契约 2）；
3. Palace 逐 Terminal 加单位电位求解，输出 `postpro/terminal-C.csv`（**法拉**）；`parse_capacitance` ×1e15 得 Maxwell 矩阵
   （fF，+对角 −非对角），NaN/Inf 直接 raise；
4. `solve_circuit_model`：接地单岛取 Maxwell 矩阵的逆，C_Σ,k = 1/[C⁻¹]_kk，E_C = e²/2C_Σ，f01、α、β = |C⁻¹_ij|/√(C⁻¹_ii C⁻¹_jj)、g；
5. 落盘 `results.yaml` + `manifest.yaml`（输入 sha256）。

参数化版产品路径那次的 Maxwell（fF）：对角 160.38 / 86.90 / 89.12（CPLR / QB1 / QB2），C_1c = 5.00、C_2c = 4.87、C_12 = 0.13——
三节点接地网络，与 Table VI 的记号一一对应（论文 95 / 228 / 98、5.36 / 5.36 / 0.125）。

**产品路径与手工路径。** 参数化版契约级是一次完整的 `build(solve=True)`：本机划网格 → `PALACE_BIN` 垫片把 config + mesh 送到 96 核 /
384 G 远端机（gpu4，np = 32）→ 拉回 postpro → 约化，共 46 min，`manifest.yaml` 记录输入 sha256 可复核。描摹版契约级则是为省 33 分钟
重划、从现成 `.msh` 重建 Mesh 对象、直接调 `palace_remote.sh`、手工 `parse_capacitance` + `solve_circuit_model` 得到的（峰值内存 168 G）；
两条路径的中间件相同，只是没有 manifest。原件都在 `.claude/xmon-evidence/`。

**这个例子没有测试断言**：它是预测，不是判据；结果写在两份 meta 头注。契约 N15 的断言对的是替代几何（§8）。

## 5. order 1 / order 2 / 粗细网格

Palace 的 `Solver.Order` 是有限元基函数的多项式阶：order 1 每个四面体上用线性函数、未知量在顶点；order 2 用二次函数、未知量在顶点加
边中点——同一张网格，未知量约多 7～8 倍。有限元是在有限维子空间里做能量极小化，子空间比真实解空间小，得到的场能只可能 ≥ 真值，
所以**电容从上方收敛**；导体边缘电场 ∝ r^(−1/2) 奇异，一阶元在那里最吃亏，而电容误差恰恰集中在边缘。梳齿与十字**全是边缘**，
所以这块几何的阶效应比矩形 pad 更大。

**真版图上的实测**（全部同向）：

| 对照 | QB1 | CPLR | QB2 | 变化 |
|---|---|---|---|---|
| 160/10，order 1 → order 2（同网格只换阶） | 108.45 → 92.0 | 204.62 → 169.3 | 113.36 → 95.6 | **−15 / −17 / −16%** |
| order 2，160/10 → 80/2（同阶加密，描摹版） | 92.0 → 87.78 | 169.3 → 160.57 | 95.6 → 91.20 | **−4.6 / −5.2 / −4.6%**，仍未收敛 |
| 阈值 143.5 → 120（同粗网格 o1，几何微变） | +2.5% | +4.0% | +6.1% | 测量误差的主导项（§3 B） |

CPLR 那条链最直观：P1 粗档 205 → P2 粗档 169 → P2 细档 160 fF，一路从上往下；连 P1 的过估（205）都已在论文 228 之下。Xmon 亦然：
P1 粗 108 / 113 = 论文 +9～11%，收敛到 P2 细 88 / 91 = −11～12%——"P1 粗档接近论文"是离散过估的巧合，与仓里 two_pads（同网格
order 1→2 对角 −4.1%、非对角 −6.7%）和替代几何（−5.1～−5.5%）是同一回事，只是这里边缘更多、幅度更大。

β 是逆电容元素的**比值**，离散偏差在分子分母上部分抵消，但这里 C_1c（5.0 fF）本身是边缘主导的小量：β_qc 粗 o1 0.035 → 细 o2 0.042，
变化比替代几何（0.0390 → 0.0393）大得多。

**代价**：契约配方 order 2 需要 384 G 级机器（描摹版峰值 168 G；64 核 / 128 G 机在多重网格层级组装处被 OOM 杀），参数化版连本机划
网格全程 46 min；同网格 order 1 本机 4 rank 几十秒即可。误差估计器即使不做 AMR 也会跑，内存预算必须把它算进去。**契约配方仍未收敛**：
两档跨 ~5%，方向已知，真值在报出值以下的某处，多远要做收敛扫（backlog #26）。

## 6. 独立求解器：Elmer 在同一张网格上

把描摹版粗网格（160/10，276k 四面体）**原样**用 `ElmerGrid 14 2` 转成 ElmerFEM 网格，写一份 `StatElecSolve` sif（一阶元，
`Calculate Capacitance Matrix`，`Coordinate Scaling 1e-6` 与 Palace 的 `L0` 同义），Terminal 与 Palace 完全相同；与 Palace order 1 在
**同一张网格**上比：

| 粗网格 P1 | QB1 | CPLR | QB2 | β_1c / β_2c |
|---|---|---|---|---|
| Palace order 1 | 108.45 | 204.62 | 113.36 | 0.0349 / 0.0339 |
| Elmer P1（同网格） | 108.45 | 204.62 | 113.36 | 0.0349 / 0.0339 |

整个 3×3 Maxwell 矩阵相对差 **1.9×10⁻⁷**（互容对到 7 位有效数字；对角的表观差纯是 Maxwell 约定 vs Elmer 的 SPICE 约定——Palace 对角 =
自容 + Σ互容，Elmer 对角 = 仅对地，换算后相同）。同网格隔离出的是纯"求解器对求解器"，**这钉死了一件事：真版图上 coupler 的低电容不是
Palace 或网格的 bug**——换一个完全独立的求解器在同一几何上得同一个数，剩下的差只能是几何。它也顺带验证了 backlog #25"Elmer 作第二
后端"的路径：本仓的 gmsh 网格可以直接喂 Elmer。sif 与 cap.dat 在 `.claude/xmon-evidence/`。

（v3 时期也有一条 Elmer 对照，但那是在 qiskit-metal 里按替代几何的尺寸重画、用第三方渲染器划网格、跨网格的比较，见 §8。）

## 7. 结果怎么读

**两版几何之差**（同配方）：粗网格 o1 −2.1 / −1.2 / −4.2%，β_qc +0.4%；契约级 o2 −1.2 / −0.5 / −2.4%，β −1.1 / −1.3%。被参数化省掉的
细节（视场内走线、贴着 Xmon 上臂的 L 形读出槽、SQUID 框、空气桥、1 px 级不对称）值 **1～4% 的 C_Σ**（QB2 最大——它右上有那条 L 形槽
和顶部走线），对比特–耦合器耦合**没有影响**。与 §3 的测量误差预算同量级。

**参数化版契约级的其它输出**：E_C = 0.2233 / 0.1212 / 0.2177 GHz，f01（零磁通）= 4.45 / 8.18 / 5.03 GHz，α = −221 / −121 / −212 MHz
（论文 η = −220 / −90 / −210；Xmon 的 α 直接对上，coupler 的 α 偏大与 C_c 偏小是同一件事），β_12 = 0.0032（论文 0.0013）；直接 q–q 电容
0.13 fF 与论文 0.125 数量级一致——真拓扑里它是一条真实存在的路径。g 不直接对比：论文 Table I 脚注 c 的 g 是在 ω_1 = ω_2 = ω_c = 4.16 GHz
处报的，本模型坐零磁通；折到 4.16 GHz 后 g 的偏差与 β 同源（+12～17%）。

**差距的归因：**

1. **不是求解器、网格转换或几何翻译**——§6 的 10⁻⁷ 与两版几何 ≤2.4% 的一致性。
2. **不主要是测量**——§3 最坏预算 C_Σ(Xmon) ±6～9%、C_c ±8～10%。阈值偏低（更多金属）的方向恰是 C_Σ↑、β↓，朝论文靠，半窗移动
   即可吃掉 2.5～6% 的 C_Σ 差与 3～6% 的 β 差：Xmon 那 12% 里**测量误差可能占一半**。C_c 的 −30% 任何合理阈值都到不了。
3. **是几何。** 论文 Table VI 的 C_c = 228 fF 是**集总模型的总电容**，含二维顶层照片里没有的结构：读出爪、空气桥、SQUID 环与封装环境；
   梳齿本身全是边缘，在照片分辩率（1.5 µm/px）与本网格下也最难解析。粗细两档 coupler 都 ~30% 低、两版几何也都 ~30% 低，说明是
   缺失结构，不是网格噪声。此外零厚度金属与 E_J 取零磁通最大值也是模型口径，不是测量。
4. **这是业界的真实精度量级**（`docs/physics.md`「精度参照系」）：SQDMetal 三求解器互差 <0.3%，但对**实验**频率 RMSE ~6%、g RMSE ~24.5%
   ——仿真间一致 ≠ 对器件预测准。本例用不完整的顶层几何预测到 12～30%，方向和量级都在这个现实里。

要把 coupler 也做进 ±10%，需要的不是调参，而是补画照片外的结构（读出腔耦合、空气桥）并对齐真实层叠——那是又一轮建模。**不能做的事**
是回头改参数去凑 99.3 / 227.9 / 101.9：用尚未收敛的网格再标定一次，只是把"命中"变成另一次抵消（§8）。

## 8. 替代几何 `sung_2021_device` 是什么，为什么它对论文 ±3～6%

仓里另一个例子 `sung_2021_device` 是三个**浮动双 pad** transmon（矩形 pad × 2 + pocket，v3 第一版就是这个拓扑，v4 逐字继承），
**不是论文版图的描摹，而是按论文集总参数标定的替代几何**：2026-07-28 在 v3 分支上、以 qiskit-metal 重画 + ElmerFEM 一阶解为尺子，
从 C_Σ 只有论文 1/4.5 的初版一路把 pad 尺寸与间距调到 102.1 / 232.8 / 102.1 fF（论文 ×1.028 / 1.021 / 1.002）。契约 N15 的断言
（C_Σ ±8%、β ±20%）对的是它。

它在 v4 order 2 契约配方下是 95.83 / 220.72 / 95.82（×0.965 / 0.969 / 0.940）。这个 −3～6% 不是精度，是**标定的抵消**：一阶元比收敛值
高 5～6%（同网格 order 1 → 2 实测 −5.1～−5.5%），被调到"看起来等于论文"的几何，收敛值必然比论文低 5～6%；"Elmer 档 ±3% 吻合"
的两边分别是"几何偏低"和"一阶偏高"，相加得零。所以 N15 的 ±8% 衡量的是**标定收敛度**，不是对真器件的预测精度——后者就是本文
真版图给出的 12～30%。两块几何角色互补：替代几何做管线自参照回归（v4 order 1 对 v3 Elmer 一阶 0.993 / 0.999 / 0.992，跨网格），
真版图标出预测边界。

替代几何的完整账（Maxwell 矩阵结构、差分双岛约化、C_12 结构性相消、g 的频率折算、容差 ±5%→±8% 的翻案、v3 Elmer 旁路的每一步）
在 `docs/physics.md` §12、`examples/sung_2021_device.meta.yaml` 头注与 `v4-dev:.claude/n15-evidence/`；两处待订正的措辞（g 参考频率
5.45 → 4.16 GHz；缺口因果首先是标定而非"版图缺失"）记在 `plan.md`。

## 9. 验证了什么、没验证什么、下一步

**验证了的**：

- 从照片量出的真拓扑（两版）经 `.geo` + sidecar → Palace → 约化整条链跑通；Palace order 1 与 Elmer 同网格一致到 10⁻⁷，两版几何契约级
  一致到 2.4%；
- 一阶元正偏与从上方收敛在这块全是边缘的几何上被直接量出（换阶 −15～17%，加密 −5%）；
- 照片测量有可复现的方法、审计图与误差预算（阈值主导，FEM 实测半窗 +2.5～6.1%）；
- 不调参预测到论文 −12～13%（Xmon）/ −30%（coupler）/ β +12～17%，并把差距分到测量、离散、几何三处。

**没验证的**：

- 论文器件的完整电容网络——视场外的读出腔、封装环境不在模型里，Table VI 的 C_c 无法被顶层几何单独解释；
- 契约配方的收敛性——两档跨 ~5%，真值在报出值以下，多远不知道；
- 磁通工作点上的频率与 g——模型没有磁通轴；
- 5 µm 地条对 β 的敏感性、比例标定的绝对精度。

**下一步**（都在 `.claude/plan.md`）：网格收敛扫（#26）；把论文期望值做成 meta 的 `targets:` 块（#23），偏差由 `build` 报出来；
Elmer 作第二后端（#25，路径已验证）；描摹器亚像素边缘拟合与自适应阈值；参数化版补 L 形读出槽与走线；5 µm 地条的 FEM 敏感性；
替代几何两处措辞订正。
