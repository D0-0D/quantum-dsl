# quantum_dsl v4 工作汇报

> **本阶段成果**：把「芯片版图 → 静电电容矩阵 → 量子比特哈密顿量」这条链路**从零重写**为一个 1 950 行的纯 Python 包：
> 输入一份 Gmsh `.geo`（几何）+ 一份 `meta.yaml`（物理参数），一个 `build()` 同时产出**流片版图（GDS）**与**静电仿真网格**，
> 跑 **Palace** 解出电容矩阵，再换算成 **E_C / f01 / 非谐 / 耦合 g**。金属改用**零厚度片**表示，v3 的整类几何失效随之消失。
> 30 条测试全绿；两条 live 实测：two_pads 回归锚**逐位复现**，Sung et al. PRX 2021 论文器件的 C_Σ 对论文在 ±8% 内、β 在 +8%。
>
> 配套材料：代码细节问答 → [`02-代码实现详解.md`](02-代码实现详解.md)；现场演示操作 → [`03-复现与演示.md`](03-复现与演示.md)。
> 文中所有 `文件:行号` 为当前代码真实位置；所有数值均于 2026-08-26 在 conda `qdsl313` 实测（sung 数值为 2026-08-25 远端机实测）。

## 1. 一句话：这是什么、这次做了什么

`quantum_dsl` 是一套面向**超导量子芯片版图**的 DSL。它把一颗芯片拆成**两层描述**（几何 + 物理参数），一条调用同时产出
**GDS 版图**和**3D 静电网格**，跑 **Palace** 解出**电容矩阵**，再用**逆电容 LOM** 转成**量子比特哈密顿量**。

这一阶段做的事：**v4 greenfield 重写**。不是在 v3 上改，而是从空白分支开始，先写契约（`SPEC.md`）和 30 条可执行需求
（测试，起点全红），再逐个翻绿。v3 保留在 `v3` 分支作参考实现，算法（逆电容 LOM、Schur、AGM 椭圆积分）逐文件审后搬运，
其余全部重新设计。

## 2. 为什么重写：v3 的三个结构性问题

| 问题 | v3 的处境 | v4 的做法 |
|---|---|---|
| **平台** | 依赖 qiskit_metal，卡在 Python 3.10；`.metal.yaml → QDesign` 路径与 native `.geo` 双前端并存 | Python ≥ 3.13，**无 qiskit_metal**（3.13 下它装不上，平台即护栏）；只有 native `.geo` 一个前端 |
| **金属表示** | 面 extrude 成 2 µm 板再从真空里**挖空** → 与衬底顶面精确共面的 OCC 布尔要么失败要么静默损坏拓扑 → 对策 ε-nudge（衬底下移一条真空缝，ε = 1 µm 时 C 偏低 29%）、fragment scale-ladder、腔壁归位 | **零厚度片 imprint**：焊盘面直接 fragment 进衬底/真空界面，Terminal 挂内部边界面。**没有布尔减**，共面是构造性精确，整类失效结构性消失。且 2 µm 板厚本身就是 ~1% 的人为偏置（真实膜厚 100–200 nm） |
| **复杂度** | YAML 模板引擎、emit-yaml 老库、9.8k 行测试、多层适配器 | 1 950 行 src、5 个测试文件；`import quantum_dsl` 不拉起 gmsh/gdstk |

v3 选挖空是因为当年断言"Palace 拒绝内部面上的 Terminal"。v4 立项时本机复检**推翻了这个断言**：那次 abort 的根因是
作者写的 Physical 组在 imprint 路径下存活、与实现的组重叠成同一面两条边界元——捕获后清掉即愈（`mesh.py:114`）。
外部证据也一边倒：Palace 官方 CPW/transmon 例、KQCircuits、SQDMetal 基准、Ansys Q3D 惯例全是零厚度 PEC 面。

**不做清单**（写进 SPEC）：qiskit_metal 任何形式、`.metal.yaml`、v3 模板引擎、qubit 参数化 cell 库（以后按新 cells API 另立项）。

## 3. 整体架构

### 3.1 数据流：两层输入 → 两路产物 → 电路模型

```
 two_pads.geo ─────────┐
 (几何, µm, 四段名)     ├─► build_gds ────► two_pads.gds                  ① GDS (µm 逐字, 旁路网格)
 two_pads.meta.yaml ───┤
 (材料/域/网格/结)      ├─► build_mesh ───► two_pads.msh ─► palace_config ─► two_pads.json   ②③ 网格 + config
                       │                                          │ solve=True
                       │                                    Palace ─► terminal-C.csv ─► parse_capacitance   ④ C 矩阵
                       │                                                                       │
                       └─► solve_circuit_model ◄───────────────────────────────────────────────┘   ⑤ 逆电容 LOM
                                    │
                             results.yaml  (E_C, f01, α, β, g)  +  manifest.yaml (输入/输出 sha256)
```

**读法**：①–③ 不需要 Palace，几秒完成；④⑤ 只在 `solve=True` 时发生。整条链只有一个编排函数 `build()`
（`build.py:145-223`）。

### 3.2 模块地图

| 阶段 | 模块 | 行 | 职责 |
|---|---|---|---|
| 输入 | `units.py` / `geo.py` / `meta.py` | 70 / 80 / 92 | 单位（µm 内部、SI 物理量）· `.geo` 加载与四段名校验 · sidecar 加载（未知键 raise） |
| 几何分叉 | `gds.py` / `mesh.py` | 88 / 286 | GDS µm 逐字 · **零厚度片 imprint** 网格 + 边缘尺寸场 + 失效防线 |
| 求解 | `palace.py` | 135 | Palace config（`L0 = 1e-6` 唯一换算点，`Order = 2`）· CSV → fF |
| 物理内核 | `circuit_model.py` / `assemble.py` / `cpw.py` | 423 / 129 / 215 | 逆电容 LOM（含浮动双岛、SQUID、χ）· 拼装 + Schur · CPW 自洽集 |
| 生成 | `cells.py` | 99 | 圆角多边形 → `.geo` 文本 |
| 编排 | `build.py` | 223 | 产物 + manifest + 分块派生 + 跑 Palace + `results.yaml` |
| 地基 | `errors.py` / `_gmsh.py` | 10 / 54 | 唯一异常 · 进程级共享 gmsh session |

依赖无环，`build` 是唯一顶点；第三方库全部惰性 import。

### 3.3 绑定键：一根线串起所有阶段

`.geo` 里每个面的 Physical 名 `role::layer::component::primitive`。**component 段 = 电学岛（net）**：它是电容矩阵
行列标签、`circuit_model` 的 `island(s)`、`assemble` 的节点名、分块的 `components` 键。
浮动 transmon 的两块 pad 必须是不同 component（`QB1_t` / `QB1_b`），器件归组写在 meta——写成同一 component 会把结短路，
v3 实测 C_Σ 错 1.70× 而测试全绿。C 矩阵行序 = `sorted(component)`，全链唯一真相源（`mesh.py:47-49`）。

## 4. 能力逐项

### 4.1 几何：手写 `.geo`，或从 Python 发射
- 手写 OCC `.geo`（µm），支持变量 / 宏 / `Include`（`examples/qlib.geo` 提供 PAD / CPW / JUNCTION / GROUND_CUTOUT 宏）。
- `rounded_polygon` + `emit_geo`（`cells.py`）：给顶点和圆角半径，发射 `load_geo` 可回读的 `.geo`。

### 4.2 一份输入，两路产物
- **GDS**（`gds.py`）：面 → gmsh 粗三角化 → gdstk 布尔并，坐标 µm 逐字（`unit = 1e-6`），`gds.by_role` 决定谁进哪层；
  JJ 进 GDS 不进网格。
- **网格**（`mesh.py`）：按 meta 合成衬底 + 真空盒，一次 `fragment` 把导体面 imprint 进 z = 0 界面；Distance + Threshold
  尺寸场对所有导体边缘曲线细化；7 条失效防线（拓扑不变量 / 空网格守卫 / 作者组清除 / out_map 归属 / 泄漏检查……）。
  two_pads：3.9 s，9 MB msh。

### 4.3 静电求解：Palace → 电容矩阵
- `palace_config`：`Model.L0 = 1e-6`（仓库唯一 µm→m 换算点），`Solver.Order = 2`（**承重件**：同网格 order 1 偏 +7.3%），
  Terminal 按 labels 编号，场输出关。外边界 `ground`（接地盒）或 `open`（须有 `ground::` 面）。
- `parse_capacitance`：Palace 输出 SI 法拉 → fF；mutual 矩阵由 Maxwell 代数导出；NaN/Inf 拒绝。

### 4.4 电容矩阵 → 哈密顿量（逆电容 LOM）
- `C_Σ = 1/[C⁻¹]_ii`（**不是** Maxwell 对角），`E_C = e²/2C_Σ`，`f01 = (√(8E_C E_J) − E_C)/h`，`α = −E_C/h`，
  `β = |C⁻¹_ij|/√(C⁻¹_ii C⁻¹_jj)`，`g = ½β√(f01_i f01_j)`。
- **浮动（差分）transmon**：结支路变换后完整求逆取 θθ 块（Yanay et al. 2020 同口径）——v3 做不到的事（issue #20）。
- 非对称 SQUID 无奇点式；χ 非 RWA 三能级二阶式；TL 谐振器等效 LC。
- 防线：反对称残差超阈值 raise、未认领 label 禁止静默接地、L_J 拒 NaN/Inf。

### 4.5 拼装与 CPW
- `assemble(cells, keep)`：共享节点累加 + Schur 消元，显式 `keep`（拼错 raise）。与 qiskit-metal LOM 2.0 机制同构，
  但 SPEC 写明**切块纪律**：有意直接耦合的导体对必须同块共现，`build()` 对几何邻近却从不共现的导体对告警。
- `lumped_cpw` / `guided_wavelength`：AGM 椭圆积分，**Z0 / λ_g 由总 L′ = Lext + Lk 导出**（不再是 c/√ε_eff）。

### 4.6 编排与可追溯
- `build(meta, out, solve=)`：GDS + mesh + config + `manifest.yaml`（输入输出 sha256）；`extract.blocks` 派生
  `block_<name>.geo/.msh/.json`；`solve=True` 跑 Palace 写 `results.yaml`。远端大内存机可用 `tools/palace_remote.sh`
  作 `PALACE_BIN` 垫片，产品代码不感知远端。

## 7. 当前边界与后续（诚实清单）

- **契约配方尚未收敛**：sung 80/2 与 160/10 两档 C_Σ 跨 ~5.5%，更细只会更低。给真实器件报数要做两档网格 + 域尺寸扫（#26）。
- **分块是 quasi-lumped 近似**：跨块直接互容结构性为零，不总是小量（相消型 coupler 对它敏感）。整片求解是默认；
  `build(solve=True)` 只解整片，分块结果的拼装由调用方走 `assemble()`。
- **LOM 微扰式**：EJ/EC ≈ 20 时首阶展开带几个百分点误差；测试钉自洽性（1e-9），不是物理精度到第 9 位。
- **g 的口径**是文献分叉处（f01 支 vs f_p 支，差 5～8%），跨文献比较先对口径。
- **N15 需要 384 G 机**：18.5M 未知量峰值内存 154 G，128 G 机必 OOM（signal 9 无诊断）。
- **无 CI、无 CLI**：只有 Python API；默认测试在 CI 上装 gmsh 即可跑（Palace 装不起——live 正好 skip）。
- `subsystems:` 键接受但不消费；χ / 谐振器 LC 计算器需手动调用。
- v4.0 留在 Palace 0.16（0.17 无静电行为变化）。
