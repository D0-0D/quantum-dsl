两者描述的是同一个静电系统，只是约定不同：Maxwell 矩阵是 Palace 直接解出的"原始"形式，mutual 矩阵是转成电路工程师习惯的"物理电容"形式。

1. Maxwell 电容矩阵 C（"electrostatic" 约定）

定义：把电荷向量和电压向量用一个矩阵联系起来

$$Q_i = \sum_j C_{ij}, V_j$$

- $C_{ii}$（对角，正）：把第 i 个导体加到 1 V、其余全部接地时，i 上的总电荷。
- $C_{ij},\ i\neq j$（非对角，恒为负）：j 升压时在接地的 i 上感应出的（异号）电荷。

它是 Palace 求解器自然输出的形式（每次把一个导体设为 1V、其余接地，读各导体电荷 → 就是矩阵的一列）。非对角是负的，没有直接的"电容元件"物理意义——你不能把 $C_{12}=-1.976$ 当成一个接在两块板之间的电容。

2. Mutual / SPICE 矩阵 Cm（"物理电容网络"约定）

把系统等价成一张电容网络图：每个节点对地一个电容、每对节点之间一个电容。

- $Cm_{ii}$（正）= 节点 i 对地的电容
- $Cm_{ij}$（正）= 节点 i 与 j 之间的电容（就是你画电路时连在两点间的那个 $C_g$）

这才是能直接搬进 SPICE / 电路模型的"看得见摸得着"的电容。

3. 两者的换算关系

$$Cm_{ij} = -C_{ij}\quad(i\neq j), \qquad Cm_{ii} = \sum_j C_{ij} = C_{ii} + \sum_{j\neq i}C_{ij}$$

注意对角项：mutual 的对地电容 = Maxwell 对角项 减去所有耦合。直观理解——Maxwell 的 $C_{ii}$ 是"其余都接地"时的总电荷，里面已经包含了流向相邻导体的那部分；要得到真正的"对地"分量，得把流向邻居的耦合电容扣掉。

4. 用 two_pads 的数字对照

Maxwell:
[ 24.729  -1.976 ]
[ -1.976  24.729 ]
换算：
- 互容 $Cm_{AB} = -(-1.976) = 1.976$ fF  ← A、B 之间的电容
- 对地 $Cm_{AA} = 24.729 + (-1.976) = 22.753$ fF  ← A 对地的电容

mutual:
[ 22.753   1.976 ]   对地: 22.753   互容: 1.976
[  1.976  22.753 ]

小结

┌────────────┬────────────────────────────┬──────────────────────────┐
│            │         Maxwell C          │        Mutual Cm         │
├────────────┼────────────────────────────┼──────────────────────────┤
│ 非对角符号 │ 负                         │ 正                       │
├────────────┼────────────────────────────┼──────────────────────────┤
│ 对角含义   │ 全接地时的总电荷/电压      │ 节点对地电容             │
├────────────┼────────────────────────────┼──────────────────────────┤
│ 非对角含义 │ 感应电荷系数（无器件意义） │ 节点之间电容 $C_g$       │
├────────────┼────────────────────────────┼──────────────────────────┤
│ 用途       │ 求解器原始输出、能量计算   │ 直接进电路/SPICE、读耦合 │
├────────────┼────────────────────────────┼──────────────────────────┤
│ 信息量     │ 完全等价（可无损互换）     │ 完全等价                 │
└────────────┴────────────────────────────┴──────────────────────────┘

两者信息完全等价、可无损互换；区别只在"用哪种视角去读"。求电场能量、做矩阵求逆推 $E_C$ 用 Maxwell 形式；想知道"A 对地多少、A-B 之间多少"、接电路仿真，就看 mutual 形式。代码里 chip.results.yaml 两个都给，就是这个原因。
